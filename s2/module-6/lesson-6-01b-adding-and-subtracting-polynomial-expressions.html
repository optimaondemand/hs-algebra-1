📚 VOCABULARY

Algebraic Expression: This is a mathematical phrase that can include numbers, variables, and operation symbols. For example, \(2x+3\) is an algebraic expression.

Coefficient: This is a number used to multiply a variable. For example, in \(5x\), the number \(5\) is the coefficient.

Constant: Unlike a variable, a constant is a number on its own, or sometimes a letter that stands for a fixed number. For example, in the expression \(3x+2\), the number \(2\) is a constant because it doesn't change.

Polynomial: A polynomial is an algebraic expression consisting of variables and coefficients, involving operations of addition, subtraction, multiplication, and non-negative integer exponents of variables. It can have one or more terms. Examples include \(4x^2\) (a monomial), \(3x+2\) (a binomial), and \(-5x^2+3x-7\) (a trinomial).

Term: In algebra, a term can be a single number, a variable, or numbers and variables multiplied together. For instance, in the expression, \(3x+2\), \(3x\) and \(2\) are both terms.

Variable: In mathematics, a variable is a symbol used to represent an unknown or changing quantity. The most common variables are \(x\), \(y\), and \(z\), though any lowercase letter can be used as a variable.

💡 EXPLORING THE MATH

In today's lesson, we will be learning how to add and subtract polynomials with 2 or 3 terms to generate an equivalent expression representing the sum or difference. We will explore representing the problem through a model using algebra tiles. Then we will explore various methods for finding the sums or differences of polynomials.

Let's begin by exploring creating models using algebra tiles. Watch the video to see how to set up a model using algebra tiles and find the sum of two polynomial expressions. Then you will learn how to find the sum or difference of two polynomials using different methods.

 

Now let's look at a couple of examples of adding and subtracting polynomials using the two methods shown in the video.

We will begin with using the associative and commutative properties to collect like terms and combine them using their signs. Then, we will look at lining up the polynomial expressions, leaving spaces, or inserting 0 as placeholders for missing terms.

Method 1: Collecting like terms using associative property.

Find the sum.

\((3x^3+5x-7)+(5x^3-2x+4)\)

Solution:

For this first problem, we will collect like terms. For a term to be like, it must contain the same variable(s) and have the same exponent on the variable(s).

We see that \(3x^3\) and \(5x^3\) are like terms, \(5x\) and \(-2x\) are like terms, and \(-7\) and \(4\) are like terms.

When we collect like terms, we take the sign that is with them in the original problem.

So, we get \((3x^3+5x^3)+(5x-2x)+(-7+4)\).

Now that we have collected like terms, we combine them by adding the coefficients and constants.

This creates the expression \(8x^3+3x-3\) as our final answer.


Method 2: Lining up the polynomials. Using space or 0 as placeholders for missing terms.

Find the sum.

\((-6x^2+8x-10)+(3x^2+15)\)

Solution:

For this example, we will explore finding the sum by lining up the expressions. When we line them up, we want to make sure to line up the like terms. If a term does not have another one like it in the other expression, then we leave a space or put in 0 as a placeholder to ensure all like terms are lined up for adding.

So in the first step, when we observe the two polynomials given we notice that the second polynomial has no x term like the first one has. So, when we line them up we will leave a space in the second polynomial where the \(x\) term would go. You can also put \(0x\) in its place. This ensures the constant of the second parenthetical expression stays aligned with the constant of the first expression, minimizing the risk of a miscalculation.

Once the like terms are lined up, we combine them following the rules of adding and subtracting integers using the coefficients of each term and the constants.

For the first term we have \(-6+3\) which equals \(-3\) and we bring down the \(x^2\) to create the term \(-3x^2\). Since there is only one \(x\) term, \(8x\), we bring it down. Adding 0 to anything does not change it.

Last, we combine the constants \(-10+15\) to create the constant \(5\).

This creates the equivalent expression \(-3x^2+8x+5\) as our final answer.

 

Try it out!

Find the sum of \(-8x^2+13x-15\) and \(17x^2-21x+2\).

Check yourself.

To find the sum combine the coefficients \((-8+17)x^2+(13+-21)x+(-15+2)\).

The answer is \(9x^2-8x-13\).

 


Last, we will look at an example of subtracting two polynomials. We will explore the same example using both methods side by side.

Example 1

Find the difference \((12x^3-9x^2+x)-(-4x^2+3x+11)\).

Solution:

This image shows the same problem worked out using both methods.

In the first method, when we collect like terms, it is very important that we remember to distribute the subtraction sign or subtract the second term as we collect the like terms. There is an \(x^3\) term in the first ( ), but not in the second polynomial. So, it remains \(12x^3\) as there is nothing to subtract from it.

For the next term, we have \(-9x^2\) and \(-4x^2\). We need to subtract the second term. Therefore, it becomes \(-9x^2--4x^2\) when we collect like terms. Following the integer rules for adding and subtracting, subtracting a negative becomes adding a positive since two negatives create a positive. Thus, the ( ) becomes \(-9x^2+4x^2\), which equals \(-5x^2\).

We continue collecting like terms, subtracting the second term as we collect them.

The second method can sometimes be a little tricky with subtraction as we need to remember to subtract the second term all the way through. Notice we put a 0 placeholder below the \(12x^3\) and above the constant \(11\) since they did not have a like term in the counterpart parentheticals to line up with them. When we combine the coefficients, the first one does not change since there is nothing to subtract. In the second term, we do \(-9--4=-9+4=-5\). For the third term, we do \(1-3=-2\) and for the last term, we need to think of it as \(0-11\).

After combining like terms by subtracting the coefficients in both methods, we end up with the equivalent expression \(12x^3-5x^2-2x-11\) as our final answer.

 

Try it out!

Find the difference between \(7x^2+4x-9\) and \(11x^2-8x+13\).


Check yourself

To find the difference subtract the coefficients of each term \((7-11)x^2+(4--8)x+(-9-13)\).

The answer is \(-4x^2+12x-22\).


Conclusion

When adding and subtracting polynomials, you will combine the coefficients of like terms using the integer rules for adding and subtracting. In order to add or subtract two polynomials, you should line up the like terms and put in 0's as placeholders for any missing terms. Remember that like terms are terms that have the same variable(s) and power.
