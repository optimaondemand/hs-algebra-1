🎮 ACTIVITY YOU'LL COMPLETE

In this activity, use Engage and AI to build, explore, and explain polynomial expressions using IFXs (interactive function extensions), numbers 0-9, variables, and other math-related IFXs to visualize polynomial structures, perform operations on them, and create instructional myrecs (recorded explanations) to demonstrate understanding. 

Begin by building representations of three different types of polynomials: monomial, binomial, and trinomial. Use the web browser on the tablet and an AI of choice to generate these polynomials. Use the IFXs to build those given polynomials in the environment by placing numbers, variables, and operation symbols to visually construct each polynomial. Identify the parts of each expression, including coefficients, variables, and exponents, and classify them as linear, quadratic, or polynomial. Once built, record a myrec explaining the different types of polynomials and labeling their parts in the VR environment.

Next, using AI chat, generate 2 polynomials that can be added and subtracted. Build these polynomials in the environment using IFXs. Using the 3D pen, add together two polynomials. Then subtract the two polynomials. Compare the results to see how like terms combine when adding versus when subtracting. After completing this, create a second myrec explaining how addition and subtraction of polynomials work, using the models as a visual aid.

Finally, using AI chat, generate an example of a monomial times a polynomial, multiplication of two binomials, and dividing a monomial into a polynomial. Build these polynomials in the environment using IFXs. Using the 3D pen, multiply and divide the polynomials. After completing these operations, create the final myrec explaining the processes of multiplying and dividing polynomials step by step in the space using the models created.
