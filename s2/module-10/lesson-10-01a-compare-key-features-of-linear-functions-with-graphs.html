📚 VOCABULARY

Domain: The set of all possible input values (x-values) that can be used in a function.

End Behavior: Describes what happens to the values of y as x becomes very large (approaches positive infinity) or very small (approaches negative infinity).

Linear Function: A function that creates a straight line when graphed and can be written in the form \(y=mx+b\) where \(m\) is the slope and \(b\) is the y-intercept.

Range: The set of all possible output values (y-values) that result from using the function.

Rate of Change: The ratio that compares how much one quantity changes on average relative to another; in linear functions, this is the slope.

Representation: A way to display or describe a mathematical idea, such as a graph, table, equation, or verbal description.

Slope: A measure of the steepness or slant of a line, calculated as the ratio of the vertical change to the horizontal change between two points on the line (rise over run).

Y-intercept: The point where a graph crosses the y-axis; in a linear function, this is the value of \(y\) when \(x\) equals zero.

💡 EXPLORING THE MATH

In today’s lesson, we will explore how to identify and compare key features of linear functions by examining their graphical representations. Understanding how to read a graph and determine features like slope and y-intercept is a foundational skill in algebra. We will also learn how to analyze and compare the domain, range, and end behavior of multiple linear functions presented as graphs. These skills help us make sense of patterns, predict future behavior, and describe relationships between variables.


Comparing Domain, Range, and End Behavior

The domain of a function includes all possible input values (x-values). For linear functions represented with solid, unbroken lines that continue in both directions, the domain is typically all real numbers.

The range is the set of all possible output values (y-values). Like the domain, the range of an unrestricted linear function is usually all real numbers since the graph continues infinitely up and down.

End behavior describes what happens to the function values as x moves toward \(\infty\) or \(-\infty\).

For example:

  • If the slope is positive, as x increases, y increases (rises to the right).

  • If the slope is negative, as x increases, y decreases (falls to the right).


To compare the domain, range, and end behavior of two or three graphs, ask yourself:

  • Do all the lines extend forever left and right? If so, their domain is the same.

  • Do they continue upward or downward without stopping? That means they also share a similar range.

  • Which direction do the lines go as you move to the far left or far right? This reveals the end behavior.

Identifying Slope and Y-Intercept from a Graph

To analyze a linear function from its graph:

  • When looking at a graph of a linear function, the slope can be found by selecting any two clear points on the line and calculating the “rise over run” or the slope by finding the rise (change in y) and run (change in x).
  • The slope tells you how steep the line is and whether it increases (positive slope) or decreases (negative slope) as it moves from left to right. You can determine the steepness by looking at whether it is rapidly increasing or decreasing versus gradually increasing or decreasing.
    • A slope that rapidly increases or decreases could be considered more steep than a slope that is gradually increasing or decreasing.
  • Next, identify the y-intercept, which is the point where the line crosses the y-axis. This point has an x-coordinate of 0, and the corresponding y-value.
    • This tells us the starting value of the function. On a graph, it is easy to locate this point because it is the only place where the value of x is zero.

 

When comparing two or three linear graphs, observe:

  • How steep each line is (which tells you about the magnitude of the slope). A steeper line means a larger absolute value of the slope.
  • Where each one crosses the y-axis. 



Example 2

The graphs of two linear functions are shown.

Linear Function A Linear Function B

Compare the slope and y-intercepts of the linear functions.

Solution:

  • We can begin by observing the slopes. We can find the slope by counting the rise over run on the graphs or picking two points and using the slope formula \(m=\frac{y_2-y_1}{x_2-x_1}\).
  • Notice that the slope of Function A is \(m=-\frac{1}{4}\) and the slope of Function B is \(m=2\).
    • The slope \(m=-\frac{1}{4}\) decreases gradually while the slope \(m=2\) increases rapidly.
  • This means that function A is less steep than function B.
  • Now, we will compare the y-intercepts of the functions.
  • Function A starts at \(-1\) while function B starts at \(2\).
  • Therefore, function A starts lower on the graph than function B does.



Example 3

The graphs of two linear functions are shown.

Linear Function A Linear Function B

Compare the slope and y-intercepts of the linear functions.

Solution:

  • We can begin by observing the slopes. We can find the slope by counting the rise over run on the graphs or picking two points and using the slope formula \(m=\frac{y_2-y_1}{x_2-x_1}\).
    • To find the slope of function A, we can start at the point \((2,-1)\) and count the rise/run to point \((0,2)\).
    • We find the slope of function A to be \(m=-\frac{3}{2}\)
    • To find the slope of function B, we can start at the point \((0,-1)\) and count the rise/run to point \((3,1)\).
    • We find the slope of function B to be \(m=\frac{2}{3}\)
  • We found the slope of Function A is \(m=-\frac{3}{2}\) and the slope of Function B is \(m=\frac{2}{3}\).
    • The slope \(m=-\frac{3}{2}\) decreases more rapidly than the slope \(m=\frac{2}{3}\).
  • This means that function A is more steep than function B.
  • Now, we will compare the y-intercepts of the functions.
  • Function A starts at \(1\) while function B starts at \(-3\).
  • Therefore, function A starts higher on the graph than function B does.



Conclusion

Today, we learned how to find the slope and y-intercept of linear functions by examining their graphs. We practiced comparing these key features across different linear graphs to determine which line is steeper or where each one starts. We also explored how to describe and compare the domain, range, and end behavior of linear functions. These skills are useful for analyzing patterns in real-life scenarios and understanding the behavior of functions beyond just their equations. Keep practicing with various graphs to build a strong foundation in interpreting and comparing linear relationships.
