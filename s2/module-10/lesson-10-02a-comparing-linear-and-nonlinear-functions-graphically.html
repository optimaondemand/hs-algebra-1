📚 VOCABULARY

Curvature: The amount by which a curve deviates from being a straight line; curved graphs show curvature, straight lines do not.

Decreasing: A function is decreasing on an interval if the output values go down as the input values increase.

Domain: The set of all possible input values (x-values) for a function.

End Behavior: The direction a graph heads as x-values become very large (positive infinity) or very small (negative infinity).

Exponential Function: A function in which the variable is an exponent, usually written as \(y=ab^x\), where \(b>0\) and \(b\neq 1\).

Intercept: The point where a graph crosses the x-axis (x-intercept) or y-axis (y-intercept).

Increasing: A function is increasing on an interval if the output values go up as the input values increase.

Interval: A specific range of x-values used to describe where a function behaves a certain way.

Linear: A relationship that forms a straight line when graphed and has a constant rate of change.

Linear Function: A function written in the form \(y=mx+b\); it graphs as a straight line.

Nonlinear: A function whose graph is not a straight line and does not have a constant rate of change.

Quadratic Function: A function written in the form \(y=ax^2+bx+c\); its graph is a U-shaped curve called a parabola.

Range: The set of all possible output values (y-values) for a function.

Slope: The steepness of a line; the ratio of the vertical change to the horizontal change between two points on a linear graph.

Comparing Linear vs Nonlinear Functions Graphically

What to look for when comparing:

1. Domain and Range

  • Linear functions usually have a domain and range of all real numbers \(-\infty <x< \infty\) and \(-\infty <y<\infty\).
  • Quadratic and Absolute Value functions have a domain that is all reals, but restricted ranges based on their vertex.
  • Square root functions  have a domain restricted like \(x\geq 0\) or a similar shift.
  • Cubic functions have domains similar to linear functions; all reals \(-\infty <x< \infty\) and \(-\infty <y<\infty\).
  • Exponential functions have a domain that is all reals, but the range is typically restricted to \(y>0\).

2. Increasing or Decreasing Intervals

  • Linear is either all increasing or all decreasing.
  • Quadratics and Absolute Values change directions at the vertex, like increasing to decreasing or vice versa.
  • Cubic may increase, then decrease, then increase again. They can change directions at peaks and valleys viewable in the graph.
  • Square root and exponential typically are increasing or decreasing in one direction only.

3. Intercepts

  • Look for where the graph touches or crosses the x- and y-axes.
  • Not all graphs will have both.

4. Positive or Negative Sections

  • Positive sections = graph is above the x-axis
  • Negative sections = graph is below the x-axis

5. End Behavior

  • Linear: Continues up or down forever in one direction
  • Quadratic: Both ends continue up or both ends continue down
  • Exponential: Increases or decreases very rapidly, one end approaches infinity while the other approaches 0.
  • Absolute Value: Both ends increase or both ends decrease
  • Square Root: has one direction that slowly approaches infinity, other ends
  • Cubic: ends go in the opposite direction like Linear

  • For B, remember to always read a graph from left to right. If we follow the linear function from left to right, we go down which is decreasing. Then if we follow the nonlinear function from left to right, we are gradually going up. 
    • Option B is true
  • For C, we see that the Linear function extends in both directions on the graph allowing the use of any x value. However, the nonlinear function starts at x=-1 and only goes to the right. This restricts the domain for the nonlinear function.
    • Option C is not true X
  • For D, we can use what we learned above for Option C. We know the linear function has an unrestricted domain, while the nonlinear function has a domain restricted starting at -1 and moving right which is towards positive infinity. 
    • Option D is true
  • For E, we need to look at what the graphs are doing as we move from left to right. If the graph is going up, it is approaching infinity. If the graph is going down, then it is approaching negative infinity. We notice the linear is going down, while the nonlinear is slowly going up. 
    • Option E is true
  • For F, we can use what we learned when observing the graphs for Option A. We found that the Linear function crosses at 3, while the Nonlinear function crosses at 1. Since 3 is greater than 1, the Linear crosses the y-axis a greater value. 
    • Option F is true

  2. Function B has a greater y-intercept than Function A.

    • Option B is true
  • For C, we will observe the graphs to see where they cross or touch the x-axis this time, if at all. We notice Function A crosses the x-axis at 2. However, Function B does not even cross the or touch the x-axis.
    • Option C is not true X
  • For D, we need to observe the graph to see if or when the function is below the x-axis to indicate negative values. For Function A, we notice that x values less than 2, the line is below the x-axis. For Function B, it is always above the x-axis. There are no negative values. 
    • Option D is true
  • For E, we want to observe the y-values that are possible for each graph. We notice that as we move up and down the y-axis for Function A, we can move over and find a spot one the line. However, for Function B, any y values below 2 are not accessible for the graph. This restricts the domain to values greater than or equal to 2. 
    • Option E is not true X
  • For F, we need to move along the graph towards the right and see what happens. As we move right along both graphs, we start going up without bound or ending.
    • Option F is true

Comparing Linear, Quadratic, and Exponential Functions

Key Ideas:

  • Linear: Constant rate of change
  • Quadratic: Rate of change increases or decreases; forms a U-shape
  • Exponential: Increases rapidly after a point and eventually surpasses the others


Exponential functions grow much faster than linear and quadratic functions as \(x\) gets larger.

  • A linear function increases by the same amount each step (constant rate).
  • A quadratic function increases by a growing amount, but still at a predictable, curved pace.
  • An exponential function multiplies by the same factor each step—this causes it to grow very slowly at first, but then rapidly increases as becomes large.

Eventually, no matter how steep the linear or how curved the quadratic, the exponential function will surpass both.

This makes exponential functions especially useful for modeling things like population growth, compound interest, and viral spread - where quantities grow explosively over time.
