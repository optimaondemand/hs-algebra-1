📚 VOCABULARY

Curvature: The amount by which a curve deviates from being a straight line; curved graphs show curvature, straight lines do not.

Decreasing: A function is decreasing on an interval if the output values go down as the input values increase.

Domain: The set of all possible input values (x-values) for a function.

End Behavior: The direction a graph heads as x-values become very large (positive infinity) or very small (negative infinity).

Exponential Function: A function in which the variable is an exponent, usually written as \(y=ab^x\), where \(b>0\) and \(b\neq 1\).

Intercept: The point where a graph crosses the x-axis (x-intercept) or y-axis (y-intercept).

Increasing: A function is increasing on an interval if the output values go up as the input values increase.

Interval: A specific range of x-values used to describe where a function behaves a certain way.

Linear: A relationship that forms a straight line when graphed and has a constant rate of change.

Linear Function: A function written in the form \(y=mx+b\); it graphs as a straight line.

Nonlinear: A function whose graph is not a straight line and does not have a constant rate of change.

Quadratic Function: A function written in the form \(y=ax^2+bx+c\); its graph is a U-shaped curve called a parabola.

Range: The set of all possible output values (y-values) for a function.

Slope: The steepness of a line; the ratio of the vertical change to the horizontal change between two points on a linear graph.

💡 EXPLORING THE MATH

In today’s lesson, we will explore how to compare linear, quadratic, and exponential functions when they are shown in different forms—such as equations, tables, graphs, or written descriptions. Each type of function has its own unique characteristics, but they can also behave similarly in certain ways. Understanding how to identify and compare these functions, even when they’re represented differently, will help you better describe and predict patterns in both mathematical and real-world situations.


What to Look for When Comparing Functions

When comparing different function types, look at the following key features:

  • Domain – The set of x-values the function is defined for

  • End Behavior – What happens to the function as \(x\rightarrow \infty\) or \(x\rightarrow -\infty\)

  • Y-Intercept – Where the function crosses the y-axis

  • Intervals of Increase or Decrease – When the function is rising or falling

  • Growth Pattern – Constant (linear), changing at a squared rate (quadratic), or growing rapidly (exponential)


Comparing Linear, Quadratic, and Exponential Functions

Linear Function Quadratic Function Exponential Function

💡 Key Ideas:

Linear: Constant Rate of Change

A linear function increases by the same amount each step.

➤ This creates a straight line on a graph.
➤ The rate of change is constant.

Domain: \(-\infty <x<\infty\)

Range: \(-\infty <x<\infty\)

End Behavior: One side goes up and one side goes down

💡 Key Ideas:

Quadratic: Increasing or Decreasing Rate of Change

A quadratic function increases or decreases by a growing amount, but in a predictable, curved pattern.

➤ Graph forms a U-shape (called a parabola).
➤ Rate of change is not constant—it accelerates.

Domain: \(-\infty <x<\infty\)

Range: Limited \(x\geq vertex\) or \(x\leq vertex\)

End Behavior: Both ends go up or both ends go down

💡 Key Ideas:

Exponential: Rapid Growth

An exponential function multiplies by the same factor at each step.

➤ Starts off slow, then increases or decreases very rapidly.
➤ Will eventually surpass both linear and quadratic functions as \(x\) becomes large.
➤ Graph curves sharply upward (or downward, if it's exponential decay).

Domain: \(-\infty <x<\infty\)

Range: Limited \(y>0\)

End Behavior: One side flattens and approaches 0. The other side grows rapidly or decreases rapidly.


💡 Exponential functions grow much faster than linear and quadratic functions as \(x\) gets larger.

📈 Eventually, no matter how steep the linear or how curved the quadratic, the exponential function will surpass both.

This makes exponential functions especially useful for modeling things like population growth, compound interest, and viral spread—where quantities grow explosively over time.



Example 1

Three functions are shown.

Function A Function B Function C
\(y=3x-2\)
x y
-2 0
-1 2
0 4
1 2
2 0

Compare the functions to answer the questions.

1. The domains are:

  • Similar
  • Different

2. As \(x\rightarrow \infty\), each function approaches?

  • Function A \(\rightarrow \) ____
  • Function B \(\rightarrow \) ____
  • Function C \(\rightarrow \) ____

3. Which statement is true about the y-intercepts?

  1. All functions have the same y-intercept.
  2. The y-intercept of Function A is greater than the y-intercept of Function B.
  3. Function C has the lowest y-intercept.
  4. Function B has the greatest y-intercept.

4. On the interval \(0<x<2\), what is each function doing?

  • Function A is increasing or decreasing?
  • Function B is increasing or decreasing?
  • Function C is increasing or decreasing?

Solution:

Let's look at each question and break it down to compare the functions.

1. We can look at the table above to remember the domains of each function.
We know that all functions have the same domain.

Answer 1. - Similar

2. Now, let's explore the end behavior of each function.
Function A is a linear with a positive slope. So, as x approaches infinity, the function approaches infinity as well.
Function B is a quadratic that starts out increasing, then turns at \((0,4)\) and starts decreasing. So, as x approaches infinity, the function will approach negative infinity.
Function C is an exponential growth that is rapidly increasing. So, as x approaches infinity, the function will also approach infinity.

Answer 2. - Function A \(\rightarrow \infty\)
Function B \(\rightarrow -\infty\)
Function C \(\rightarrow \infty\)

3. Now, let's observe the y-intercepts of all 3 functions.
In Function A, we know the y-intercept is \((0,-2)\) since the b value in the function is \(-2\).
In function B, when we look at the table, we look for when x=0. We notice the y-intercept is \((0,4)\) from the table.
In function C, we see in the graph that it crosses the y-axis at 1. So, the y-intercept is \((0,1)\).

Answer 3. - Function B has the greatest y-intercept.

4. Last, we will look at what each function is doing on the interval \(0<x<2\).
For Function A, we can substitute in 0 and 2 to see if we are increasing or decreasing. \(y=3(0)-2\implies y=0-2\implies y=-2\) and \(y=3(2)-2\implies y=6-2\implies y=4\). We went from -2 to 4. Therefore, the function is increasing.
For Function B, we look at the table and the x values 0 to 2 to see what the y values are doing. For x=0, the function is 4. Then for x=2, the function is 0. So, the function decreased.
For Function C, we look at what the line on the graph is doing between 0 and 2 on the x-axis. We see that the line goes up from x=0 to x=2. Therefore, it is increasing.
Two of the functions are increasing, and one is decreasing.

Answer 4. - Function A is increasing.
Function B is decreasing.
Function C is increasing.



Example 2

You are comparing three models for different types of growth over time.

Function A Function B Function C
A savings account starts with $10 and grows by $25 per week. \(y=-2x^2+20x+10\)

Compare the functions to answer the questions.

1. The domains are:

  • Similar
  • Different

2. As \(x\rightarrow \infty\), each function approaches?

  • Function A \(\rightarrow \) ____
  • Function B \(\rightarrow \) ____
  • Function C \(\rightarrow \) ____

3. Which statement is true about the y-intercepts?

  1. All functions have the same y-intercept.
  2. The y-intercept of Function A is greater than the y-intercept of Function B.
  3. Function C has the lowest y-intercept.
  4. Function B has the greatest y-intercept.

4. On the interval \(0<x<5\), what is each function doing?

  • Function A is increasing or decreasing?
  • Function B is increasing or decreasing?
  • Function C is increasing or decreasing?

5. Which model will eventually exceed the others?

Solution:

Let's look at each question and break it down to compare the functions.

1. We can look at the table above to remember the domains of each function.
We know that all functions have the same domain.
Since they are all real-world, they all start at their y-intercept and go to infinity.
Function A starts at 10, Function B starts at 10, and Function C starts at 10. So, all functions will have the same domain.

Answer 1. - Similar

2. Now, let's explore the end behavior of each function.
Function A is a linear with a positive slope since we are adding to the savings account. So, as x approaches infinity, the function approaches infinity as well.
Function B is a quadratic with a negative coefficient on \(x^2\). This means it will be an upside-down u-shape that will start increasing, then turn at the vertex and decrease. So, as x approaches infinity, the function will approach negative infinity.
Function C is an exponential growth that is rapidly increasing. So, as x approaches infinity, the function will also approach infinity.

Answer 2. - Function A \(\rightarrow \infty\)
Function B \(\rightarrow -\infty\)
Function C \(\rightarrow \infty\)

3. Now, let's observe the y-intercepts of all 3 functions.
In Function A, we know the savings account started at $10. So, the y-intercept is \((0,10)\).
In function B, when we evaluate for when x=0, \(y=-2(0)^2+20(0)+10\implies y=10\). We find the y-intercept is \((0,10)\) from the table.
In function C, we see in the graph it crosses the y-axis at 10. So, the y-intercept is \((0,10)\).

Answer 3. - The y-intercept is the same for all functions.

4. Last, we will look at what each function is doing on the interval \(0<x<5\).
For Function A, we think about if the account starts at 10 and we are adding $25 each week, then the function will increase from week 0 to week 5.
For Function B, we evaluate the function when x=0 and x=5. For x=0, \(y=-2(0)+20(0)+10\implies y=0\). Then for x=5, \(y=-2(5)^2+20(5)+10\implies y=-2(25)+20(5)+10\implies y=-50+100+10\implies y=60\). Since we went from 10 to 60, the function increased.
For Function C, we look at what the line on the graph is doing between 0 and 5 on the x-axis. We see that the line goes up from x=0 to x=5. Therefore, it is increasing.

Answer 4. - Function A is increasing.
Function B is increasing.
Function C is increasing.



Conclusion

In this lesson, you learned how to compare linear, quadratic, and exponential functions even when they are presented in different forms like equations, graphs, tables, or written descriptions. You examined their domain, end behavior, growth patterns, intercepts, and how they behave on specific intervals. One key takeaway is that exponential functions may start slow, but they eventually exceed both linear and quadratic functions over time. This understanding helps you interpret and compare patterns in real-life and mathematical situations more effectively.
