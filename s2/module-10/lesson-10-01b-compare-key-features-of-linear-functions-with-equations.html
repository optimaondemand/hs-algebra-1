📚 VOCABULARY

Domain: The set of all possible input values (x-values) that can be used in a function.

End Behavior: Describes what happens to the values of y as x becomes very large (approaches positive infinity) or very small (approaches negative infinity).

Linear Function: A function that creates a straight line when graphed and can be written in the form \(y=mx+b\) where \(m\) is the slope and \(b\) is the y-intercept.

Range: The set of all possible output values (y-values) that result from using the function.

Rate of Change: The ratio that compares how much one quantity changes on average relative to another; in linear functions, this is the slope.

Representation: A way to display or describe a mathematical idea, such as a graph, table, equation, or verbal description.

Slope: A measure of the steepness or slant of a line, calculated as the ratio of the vertical change to the horizontal change between two points on the line (rise over run).

Y-intercept: The point where a graph crosses the y-axis; in a linear function, this is the value of \(y\) when \(x\) equals zero.

💡 EXPLORING THE MATH

In today's lesson, we will explore how to use the equations of two linear functions to identify and compare key features: domain, range, end behavior, slope, and y-intercept. By learning how to compare these features using the equations, you will understand how different lines behave and how to describe them clearly using mathematical and everyday language.


Let's begin by reviewing the key features of a linear function.

Slope and y-intercept

All linear functions can be written in slope-intercept form:

\(y=mx+b\)

Where:

  • m = slope

  • b = y-intercept

Domain and Range

  • Domain (x-values):

    • For linear equations with no restrictions: \(D=-\infty <x< \infty\)

  • Range (y-values):

    • For linear equations with no restrictions: \(R=-\infty <y< \infty\)

     

  • If there are no stated limits or context-based restrictions, both domain and range are infinite.

End Behavior

  • Use the slope to determine how the line behaves at the extremes of the graph:

    • Positive slope:

      • As \(x\rightarrow \infty , y\rightarrow \infty\)

      • As \(x\rightarrow -\infty , y\rightarrow -\infty\) 

    • Negative slope:

      • As \(x\rightarrow \infty , y\rightarrow -\infty\)

      • As \(x\rightarrow -\infty , y\rightarrow \infty\)



How to Compare Slopes

The slope tells you how steep the line is and whether it increases or decreases as x increases.

  • If the slope is positive:

    • Larger numbers = rapid increase

    • Smaller fractions = gradual increase

  • If the slope is negative:

    • Larger absolute values = rapid decrease

    • Smaller fractions = gradual decrease

How to Compare Y-Intercepts

The y-intercept tells you where the function starts on the y-axis (when \(x=0\)).

  • A higher y-intercept = the line starts higher on the graph

  • A negative y-intercept = the line starts lower on the graph



Example 1

Two linear functions are shown.

Linear Function A Linear Function B
\(y=3x-4\) \(y=-\frac{2}{5}x+3.2\)

Compare the domain, range, and end behavior of each function.

Solution:

  • For the domain, both linear functions will have no restrictions.
    • The domain will be the same for both functions; \(-\infty <x<\infty\)
  • For range, both linear functions have no restrictions on the range.
    • The range will be the same for both functions; \(-\infty <y<\infty\)
  • For the end behavior:
    • Function A has a positive slope, which means it will rise to the right.
    • Function B has a negative slope, which means it will fall to the right.
    • The end behaviors will be different.



Example 2

Two linear functions are shown.

Linear Function A Linear Function B
\(y=\frac{1}{3}x+2.5\) \(y=-2x-1\)

Compare the slope and y-intercept of the two functions.

Solution:

  • Slope comparison:
    • Function A has a slope of \(\frac{1}{3}\) which is gradually increasing.
    • Function B has a slope of \(-2\) which is decreasing more rapidly than Function A.
  • Function A is less steep than Function B.
  • Y-intercept comparison:
    • Function A has a positive y-intercept of \(2.5\).
    • Function B has a negative y-intercept of \(-1\).
  • Function A starts higher on the graph than Function B.



Example 3

Two linear functions are shown.

Linear Function A Linear Function B
\(y=\frac{4}{3}x+5\) \(y=\frac{3}{4}x-5\)

Compare the slope and y-intercept of the two functions.

Solution:

  • Slope comparison:
    • Function A has a slope of \(\frac{4}{3}\) and function B has a slope of \(\frac{3}{4}\).
    • Since \(\frac{4}{3}\) is greater than \(\frac{3}{4}\), it would increase more rapidly.
  • Function A is more steep than Function B.
  • Y-intercept comparison:
    • Function A has a positive y-intercept of \(5\).
    • Function B has a negative y-intercept of \(-5\).
  • Function A starts higher on the graph than Function B.



Conclusion

You’ve now learned how to find and compare domain, range, end behavior, slope, and y-intercept from the equations of linear functions.
When comparing functions:

  • Use terms like gradually increasing, rapidly decreasing, etc., to describe slopes

  • Look at the sign of the slope to determine the direction of the line

  • Use the y-intercept to compare where each line begins on the graph

These tools help you describe relationships between functions and explain how they change in different contexts. With practice, you’ll be able to make accurate comparisons quickly and clearly.
