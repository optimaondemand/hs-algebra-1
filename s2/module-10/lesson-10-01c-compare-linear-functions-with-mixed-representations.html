📚 VOCABULARY

Domain: The set of all possible input values (x-values) that a function can take.

End Behavior: Describes what happens to the output (y-values) of a function as the input (x) becomes very large (positive infinity) or very small (negative infinity).

Linear Function: A function that graphs as a straight line and can be written in the form \(y=mx+b\), where \(m\) is the slope and \(b\) is the y-intercept.

Range: The set of all possible output values (y-values) that result from the inputs of a function.

Rate of Change: How much the output value (y) changes for a given change in the input value (x); for a linear function, it is the slope.

Representation: A way to show a function using an equation, graph, table, or description.

Slope: The measure of steepness of a line; it shows the rate of change and is calculated as rise over run.

Y-Intercept: The point where the line crosses the y-axis; it represents the output value when the input is zero.

💡 EXPLORING THE MATH

In today’s lesson, we will explore how to compare linear functions that are presented in different forms: graphs, equations, and tables. By analyzing key features like domain, range, end behavior, slope, and y-intercept, you will learn how to interpret and compare the behavior of linear relationships even when they are shown in different ways.


Comparing Domain, Range, and End Behavior

When comparing linear functions in mixed representations, follow these steps:

1. Domain

  • For most linear functions, unless there is a restriction, the domain is \(-\infty <x<\infty\).
  • From a graph: check if the line continues left and right without ending.
  • From a table: look for clues—are the x-values increasing without bound or are they limited?
  • From an equation: unless stated otherwise, assume it continues in both directions.

2. Range

  • Most linear functions also have the range \(-\infty <y< \infty\).
  • From a graph: does the line go up and down forever?
  • From a table: do the y-values grow or shrink without stopping?
  • From an equation: assume infinite range unless context limits it.

3. End Behavior

  • Identify the slope to understand end behavior:

    • If the slope is positive, the function increases: As \(x\rightarrow \infty , y\rightarrow \infty\) and as \(x\rightarrow -\infty , y\rightarrow -\infty\)
    • If the slope is negative, the function decreases: As \(x\rightarrow \infty , y\rightarrow -\infty\) and as \(x\rightarrow -\infty , y\rightarrow \infty\)



Example 1

Two linear functions are given.

Linear Function A Linear Function B
x y
-3 6
-1 2
1 -2
3 -6

Compare the domain, range, and end behavior.

Solution:

  • Domain:
    • Function A is extending infinitely in both directions.
    • Function B suggests a consistent decrease in the pattern.
    • The domain is the same for both functions.
  • Range:
    • Function A is extending infinitely in both directions.
    • Function B suggests a consistent decrease in the pattern.
    • The range is the same for both functions.
  • End Behavior:
    • Function A has a positive slope, which means it is increasing.
    • Function B shows a decreasing pattern.
    • The end behavior is different for the functions.



Comparing Slope and Y-Intercept

To compare slope and y-intercept, follow these steps:

1. Slope

  • From an equation: the slope is the number in front of \(x\).
  • From a graph: find two points, use rise/run.
  • From a table: check how much \(y\) changes as \(x\) increases.

🔑 Compare absolute values to determine steepness:

    • Larger absolute value = more steep = rapid change
    • Smaller absolute value = less steep = gradual change

2. Y-Intercept

  • From an equation: it's the constant \(b\).
  • From a graph: where the line crosses the y-axis.
  • From a table: find the output when \(x=0\).

🔑 Compare which function starts higher or lower on the graph based on y-intercepts.



Example 2

Two linear functions are given.

Linear Function A Linear Function B
\(y=\frac{1}{2}x+4.5\)
x y
0 -2
2 -6
4 -10
6 -14

Compare the slope and the y-intercept.

Solution:

  • Slope:
    • Function A has a slope of \(\frac{1}{2}\) which represents a gradual increase.
    • Function B we can pick 2 points and use the slope formula \(m=\frac{y_2-y_1}{x_2-x_1}\).
      • \((0,-2)\) and \((2,-6)\)
      • \(m=\frac{-6+2}{2-0} \implies m=\frac{-4}{2} \implies m=-2\)
      • This slope shows a rapid decrease.
    • Function A is less steep than Function B.
  • y-intercept:
    • Function A has a positive y-intercept of \((0,4.5)\).
    • Function B has a negative y-intercept of \((0,-2)\).
    • Function A starts higher than Function B.



Example 3

Two linear functions are given.

Linear Function A Linear Function B
\(y=\frac{2}{5}x+2\)

Compare the slope and the y-intercept.

Solution:

  • Slope:
    • Function A we need to find the slope by counting rise over run.
      • We can start at \((0,-3)\) and count up 11 to 8, then over 3 to 3.
      • We find the slope is \(\frac{11}{3}\) which is a rapid increase.
    • Function B we see the slope is \(\frac{2}{5}\) which is a gradual increase.
    • Function A is more steep than Function B.
  • y-intercept:
    • Function A has a negative y-intercept of \((0,-3)\).
    • Function B has a positive y-intercept of \((0,2)\).
    • Function A starts lower than Function B.



Example 4 - Real-World

Two friends, Emily and Carlos, each have savings accounts. They deposit money at a constant rate every week.

  • The equation \(y=25x+100\) represents how much money is in Emily's account after x weeks.
  • Carlos deposits $40 a week and started with $50 in his savings account.

Compare the savings habits of Emily and Carlos.

  • Who started with more money?

  • Who is saving faster?

Solution:

  • To determine who started with more money, we will compare the initial values or y-intercepts.
    • Emily started with $100 and Carlos started with $50.
    • Emily started with more money in her account than Carlos did.
  • To determine who is saving money faster or has a more rapid rate of change, we will compare their slopes.
    • Emily is saving at a rate of $25 and Carlos is saving at a rate of $40.
    • Carlos is saving money more rapidly than Emily.



Example 5 - Real-World

Two water tanks are being filled at a constant rate. The linear functions represented below show the water levels, y, over time, x minutes.

Tank A Tank B
\(y=5x+10\)

Compare how the two tanks are being filled.

  • Which tank starts with more water?

  • Which tank is filling more rapidly?

Solution:

  • To determine which tank started with more water, we need to compare the initial values or y-intercepts.
    • Tank A started with 10 gallons of water.
    • Tank B started with 20 gallons of water.
    • Tank B started with more water in it.
  • To determine which tank is filling more rapidly or at a faster rate, we will compare the slopes or rates of change.
    • Tank A is filling at a rate of 5 gallons per minute.
    • Tank B is filling at a rate of 2 gallons per minute by observing the rise/run on the graph.
    • Tank A is filling more rapidly than Tank B.



Conclusion

In this lesson, you learned how to compare linear functions that are shown as graphs, equations, or tables.
You practiced:

  • Determining domain, range, and end behavior by observing how the function behaves or continues.

  • Comparing slope and y-intercept to decide which function is more steep and which starts higher or lower.

By understanding how to read each representation, you can confidently analyze and compare any pair of linear functions—no matter how they're presented!
