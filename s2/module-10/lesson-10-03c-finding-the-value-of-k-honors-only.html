📚 VOCABULARY

Absolute Value Function: A function that contains an algebraic expression within absolute value symbols, usually written as \(f(x)=|x|\).

Horizontal Compression: A transformation that squeezes the graph of a function towards the y-axis, caused by replacing x with a multiple greater than 1, \(f(kx),k>1\).

Horizontal Stretch: A transformation that spreads the graph of a function away from the y-axis, caused by replacing x with a value between 0 and 1, \(f(kx),0<k<1\).

Horizontal Translation: A shift of the entire graph left or right, caused by replacing \(x\) with \(x\pm k\).

Linear Function: A function that creates a straight line when graphed, typically written in the form \(f(x)=mx+b\).

Quadratic Function: A function that graphs as a parabola, typically written as \(f(x)=ax^2+bx+c\).

Transformation: Any change made to the graph of a function, including translations, reflections, stretches, and compressions.

Translation: A transformation that shifts a graph horizontally, vertically, or both, without changing its shape or orientation.

Vertical Compression: A transformation that flattens the graph of a function, caused by multiplying the function by a factor between 0 and 1, \(kf(x), 0<x<1\).

Vertical Shift: A translation that moves the graph up or down, caused by adding or subtracting a constant to the function \(f(x)\pm k\).

Vertical Stretch: A transformation that makes the graph of a function taller, caused by multiplying the function by a constant greater than 1, \(kf(x), k>1\).

Vertical Translation: A shift of the graph up or down, caused by adding or subtracting a constant to the function.

💡 EXPLORING THE MATH

In today’s lesson, we will explore how to identify and describe transformations of functions by comparing the graph of a parent function \(f(x)\) to a transformed function \(g(x)\). We will focus on vertical shifts, horizontal shifts, and vertical stretches or compressions. These transformations change the appearance of a function’s graph but not its general shape. You will learn how to determine the type of transformation(s) that have occurred and identify the value of \(k\) used in the transformation. We will use quadratic functions and absolute value functions as our primary examples. You’ll also practice writing equations that represent the transformations you observe on graphs.


Understanding Transformations - Refresher

  • Vertical Shift: \(g(x)=f(x)+k\)
    • Moves the graph up k units when \(f(x)+k\).
    • Moves the graph down k units when \(f(x)-k\).
  • Horizontal Shift: \(g(x)=f(x+k)\)
    • Moves the graph left k units when \(f(x+k)\).
    • Moves the graph right k units when \(f(x-k)\).
  • Vertical Stretch/Compression: \(k\cdot f(x)\)
    • If \(k>1\), then the graph becomes taller (stretched).
    • If \(0<k<1\), then the graph becomes flatter (compressed).



Transformation Functions

Linear Function

Parent Function: \(f(x)=x\)

y-intercept: \((0,0)\)

Absolute Value Function

Parent Function: \(f(x)=|x|\)

Vertex: \((0,0)\)

Quadratic Function

Parent Function: \(f(x)=x^2\)

Vertex: \((0,0)\)

Transformation Function

\(g(x)=mx+b\)

where \(m\) is the vertical stretch or compression

\(b\) is the vertical shift

Transformation Function

\(g(x)=a|x-h|+k\)

Vertex: \((h,k)\)

where \(a\) is the value of stretch or compression

if \(a\) is negative, this will flip the graph upside down

\(h\) is the value of the horizontal shift

\(k\) is the value of the vertical shift

Transformation Function

\(g(x)=a(x-h)^2+k\)

Vertex: \((h,k)\)

where \(a\) is the value of stretch or compression

if \(a\) is negative, this will flip the graph upside down

\(h\) is the value of the horizontal shift

\(k\) is the value of the vertical shift



Example 1

The graph of the parent function \(f(x)=|x|\) and the graph of a transformed function \(g(x)\) are shown.

Parent Function \(f(x)=|x|\) Transformed Function \(g(x)\)

Identify the transformations of \(g(x)\) and write the equation for \(g(x)\).

Solution:

  • We can use the vertex of the V-shape to help us identify any vertical or horizontal shifts that may have happened.
  • The vertex of the parent function \(f(x)=|x|\) is located at \((0,0)\) and compare it against the vertex of \(g(x)\).
  • We see that the vertex of \(g(x)\) is located at \((-3,-4)\).
  • This tells us that the function shifted left 3 units and down 4 units.
  • Now, we can use that information to write the equation of \(g(x)\).
    • A transformation of left 3 units means f(x+3) since + means shift left.
      • \(h=-3\) for the transformed function
    • A transformation of down 4 units means f(x)-4 since - means shift down.
      • \(k=-4\) for the transformed function
  • Now, we put those together to create the function \(g(x)=|x+3|-4\)

Answer: The function shifted left 3 units and down 4 units. The equation is \(g(x)=|x+3|-4\).



Example 2

The graph of the parent function \(f(x)=x\) and the graph of a transformed function \(g(x)\) are shown.

Identify the transformations of \(g(x)\) and write the equation for \(g(x)\).

Solution:

  • We can use the y-intercept to help us identify any vertical shifts that may have happened.
  • The y-intercept of the parent function \(f(x)=x\) is located at \((0,0)\) and compare it against the y-intercept of \(g(x)\).
  • We see that the y-intercept of \(g(x)\) is located at \((0,3)\).
  • This tells us that the function shifted up 3 units.
  • Next, we will look at the slope of the graph to identify any vertical stretch or compression.
  • From the y-intercept of \(g(x)\), we need to rise 2 and run left 1 to get to another point on the line.
  • This makes the slope \(m=-2\).
  • Now, we can use that information to write the equation of \(g(x)\).
    • A transformation of up 3 units means f(x)+3.
    • A transformation of stretch -2 units means -2f(x).
  • Now, we put those together to create the function \(g(x)=-2x+3\)

Answer: The function shifted up 3 units and stretched -3 units. The equation is \(g(x)=-2x+3\).



Example 3

The graph of the parent function \(f(x)=x^2\) and the graph of a transformed function \(g(x)\) are shown.

Identify the transformations of \(g(x)\) and write the equation for \(g(x)\).

Solution:

  • We can use the vertex to help us identify any vertical or horizontal shifts that may have happened.
  • The vertex of the parent function \(f(x)=x\) is located at \((0,0)\) and compare it against the vertex of \(g(x)\).
  • We see that the y-intercept of \(g(x)\) is located at \((0,-3)\).
  • This tells us that the function shifted down 3 units.
  • Next, we will look at the steepness of the graph to identify any vertical stretch or compression.
  • From the vertex of \(g(x)\), we need to rise -2 and run left or right 1 to get to another point on the curve.
  • This makes a vertical stretch of \(-2\).
  • Now, we can use that information to write the equation of \(g(x)\).
    • A transformation of down 3 units means f(x)-3.
    • A transformation of stretch -2 units means -2f(x).
  • Now, we put those together to create the function \(g(x)=-2x^2-3\)

Answer: The function shifted up 3 units and stretched -3 units. The equation is \(g(x)=2x^2-3\).



Conclusion

By comparing graphs of parent functions to their transformed versions, you can determine the type of transformation and the value of k used in the equation. Today, you practiced identifying vertical and horizontal shifts, as well as vertical stretches and compressions. You also matched transformed graphs to their equations and wrote equations from observed transformations. This skill will help you understand how algebraic changes influence a graph's shape and position, a vital part of analyzing real-world functions and data.
