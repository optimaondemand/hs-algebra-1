📚 VOCABULARY

Absolute Value Function: A function that contains an algebraic expression within absolute value symbols, usually written as \(f(x)=|x|\).

Horizontal Compression: A transformation that squeezes the graph of a function towards the y-axis, caused by replacing x with a multiple greater than 1, \(f(kx),k>1\).

Horizontal Stretch: A transformation that spreads the graph of a function away from the y-axis, caused by replacing x with a value between 0 and 1, \(f(kx),0<k<1\).

Horizontal Translation: A shift of the entire graph left or right, caused by replacing \(x\) with \(x\pm k\).

Linear Function: A function that creates a straight line when graphed, typically written in the form \(f(x)=mx+b\).

Quadratic Function: A function that graphs as a parabola, typically written as \(f(x)=ax^2+bx+c\).

Transformation: Any change made to the graph of a function, including translations, reflections, stretches, and compressions.

Translation: A transformation that shifts a graph horizontally, vertically, or both, without changing its shape or orientation.

Vertical Compression: A transformation that flattens the graph of a function, caused by multiplying the function by a factor between 0 and 1, \(kf(x), 0<x<1\).

Vertical Shift: A translation that moves the graph up or down, caused by adding or subtracting a constant to the function \(f(x)\pm k\).

Vertical Stretch: A transformation that makes the graph of a function taller, caused by multiplying the function by a constant greater than 1, \(kf(x), k>1\).

Vertical Translation: A shift of the graph up or down, caused by adding or subtracting a constant to the function.

💡 EXPLORING THE MATH

In today’s lesson, we will explore how transformations of parent functions affect tables of values. We will begin by examining the tables of values for the three fundamental parent functions—linear, quadratic, and absolute value. You will learn how to analyze how different transformations, such as vertical shifts, horizontal shifts, vertical stretches/compressions, and horizontal stretches/compressions, change the outputs in the table of values. Using this knowledge, you’ll be able to match transformed functions to tables of values, describe what transformations do to the tables, and finally generate your own table of values for a given transformation.

How Transformations Affect Tables of Values

Vertical Shifts: \(f(x)+k\) or \(f(x)-k\)

  • If \(g(x)=f(x)+k\), then add \(k\) to every output, \(f(x)\). The y-values increase by \(k\) units.
    • The graph shifts up, and the table of values reflects this shift in the y-values.
  • If \(g(x)=f(x)-k\), then subtract \(k\) from every output, \(f(x)\). The y-values decrease by \(k\) units.
    • The graph shifts down, and the table of values reflects this shift in the y-values.


Horizontal Shifts: \(f(x+k)\) or \(f(x-k)\)

  • If \(g(x)=f(x+k)\), then subtract \(k\) to every input, \(x\). The x-values decrease by \(k\) units.
    • The graph shifts left, and the table reflects this shift in the x-values.
  • If \(g(x)=f(x-k)\), then add \(k\) to every input, \(x\). The x-values increase by \(k\) units.
    • The graph shifts right, and the table reflects this shift in the x-values.


Vertical Stretch/Compression: \(k\cdot f(x)\)

  • If \(g(x)=k\cdot f(x)\), then multiply each y-value by \(k\).
    • The y-values scale up \(k\) units when \(k>1\).
    • The y-values scale down \(k\) units when \(0<k<1\).


Horizontal Stretch/Compression: \(f(k\cdot x)\)

  • If \(g(x)=f(k\cdot x)\), then divide each x-value by \(k\).

Example 2

Parent Function: \(f(x)=|x|\)

Transformed Function: \(g(x)=3|x-2|\)

What will happen to the table of values for the transformed function?

Solution:

  • Let's identify the transformations first.
    • The graph of the function will vertically stretch by a factor of 3.
    • The graph will shift right 2 units.
  • Now, let's identify how that will affect the table of values.
    • The vertical stretch will cause the y-values to be multiplied by a factor of 3.
    • The horizontal shift will cause the x-values to be increased by 2 units.

Answer: The y-values will be tripled (multiplied by 3) and the each x-value will be increased by 2.

Conclusion

By examining the tables of values for linear, quadratic, and absolute value parent functions, you’ve learned how function transformations change specific x- and y-values. Understanding the effects of \(f(x)+k\), \(f(x+k)\), \(kf(x)\), and \(f(kx)\) helps you match transformations to tables, explain those changes, and generate new tables yourself. These skills not only make graphing easier but also deepen your understanding of how algebraic rules influence real-world behavior and data models.
