📚 VOCABULARY

Absolute Value Function: A function that contains an algebraic expression within absolute value symbols, usually written as \(f(x)=|x|\).

Horizontal Compression: A transformation that squeezes the graph of a function towards the y-axis, caused by replacing x with a multiple greater than 1, \(f(kx),k>1\).

Horizontal Stretch: A transformation that spreads the graph of a function away from the y-axis, caused by replacing x with a value between 0 and 1, \(f(kx),0<k<1\).

Horizontal Translation: A shift of the entire graph left or right, caused by replacing \(x\) with \(x\pm k\).

Linear Function: A function that creates a straight line when graphed, typically written in the form \(f(x)=mx+b\).

Quadratic Function: A function that graphs as a parabola, typically written as \(f(x)=ax^2+bx+c\).

Transformation: Any change made to the graph of a function, including translations, reflections, stretches, and compressions.

Translation: A transformation that shifts a graph horizontally, vertically, or both, without changing its shape or orientation.

Vertical Compression: A transformation that flattens the graph of a function, caused by multiplying the function by a factor between 0 and 1, \(kf(x), 0<x<1\).

Vertical Shift: A translation that moves the graph up or down, caused by adding or subtracting a constant to the function \(f(x)\pm k\).

Vertical Stretch: A transformation that makes the graph of a function taller, caused by multiplying the function by a constant greater than 1, \(kf(x), k>1\).

Vertical Translation: A shift of the graph up or down, caused by adding or subtracting a constant to the function.

💡 EXPLORING THE MATH

In today’s lesson, we will explore how changes in a function's equation affect its graph. Specifically, we’ll investigate horizontal and vertical compressions and stretches, as well as horizontal and vertical translations. By understanding how to modify a function using expressions like \(f(x)+k\), \(f(x+k)\), \(kf(x)\), and \(f(kx)\), you will gain the tools to predict and describe how a graph will move or change shape. These concepts are key to graphing functions quickly and understanding real-world phenomena modeled by algebraic equations.


Vertical and Horizontal Translations

  • Vertical Translation: Replacing \(f(x)\) with \(f(x)+k\) or \(f(x)-k\)
    • \(f(x)+k\) will shift it up k units
    • \(f(x)-k\) will shift it down k units

 

  • Horizontal Translation: Replacing \(f(x)\) with \(f(x+k)\) or \(f(x-k)\)
    • \(f(x+k)\) will shift it left k units
    • \(f(x-k)\) will shift it right k units

**Note that it is the opposite, a plus k makes it go left, and a minus k makes it go right.**



Vertical and Horizontal Stretches and Compressions

  • Vertical Stretch/Compression: Replacing \(f(x)\) with \(kf(x)\) alters the graph's height.
    • If \(k>1\) in \(kf(x)\), the graph stretches vertically (taller).
    • If \(0<k<1\) in \(kf(x)\), the graph compresses vertically (flatter).

 

  • Horizontal Stretch/Compression: Replacing \(f(x)\) with \(f(kx)\) changes the graph's width.
    • If \(k>1\) in \(f(kx)\), the graph compresses horizontally (squeezed).
    • If \(0<k<1\) in \(f(kx)\), the graph stretches horizontally (widened).


Linear Examples

Linear Parent Function

\(f(x)=x\)

Transformed Function

\(g(x)=\frac{1}{2}f(x)-1\)

The function will be compressed vertically and shifted down 1 unit.

\(\textcolor{red}{g(x)=\frac{1}{2}x-1}\)

Transformed Function

\(g(x)=3f(x)\)

The function will be stretched vertically.

\(\textcolor{blue}{g(x)=3x}\)

Transformed Function

\(g(x)=f(x)+3\)

The function will be shifted up 3 units.

\(\textcolor{green}{g(x)=x+3}\)



Quadratic Examples

Quadratic Parent Function

\(f(x)=x^2\)

Transformed Function

\(g(x)=2f(x-4)\)

The function will be stretched vertically by a factor of 2 and shifted right 4 units.

\(\textcolor{red}{g(x)=2(x-4)^2}\)

Transformed Function

\(g(x)=f(x+1)-3\)

The function will shift left 1 unit and down 3 units.

\(\textcolor{blue}{g(x)=(x+1)^2-3}\)

Transformed Function

\(g(x)=f(\frac{1}{2}x+2)\)

The function will be stretched horizontally by a factor of \(\frac{1}{2}\) and shifted up 2 units.

\(\textcolor{green}{g(x)=(\frac{1}{2}x)^2+2}\)



Absolute Value Examples

Absolute Value Parent Function

\(f(x)=|x|\)

Transformed Function

\(g(x)=f(2x+4)\)

The function will be compressed horizontally by a factor of 2 and shifted left 4 units.

\(\textcolor{red}{g(x)=|2x+4|}\)

Transformed Function

\(g(x)=f(x-2)+3\)

The function will shift right 2 units and up 3 units.

\(\textcolor{blue}{g(x)=|x-2|+3}\)

Transformed Function

\(g(x)=\frac{1}{4}f(x)\)

The function will be compressed vertically by a factor of \(\frac{1}{4}\).

\(\textcolor{green}{g(x)=\frac{1}{4}|x|}\)



Example 1

The graph of the parent function \(f(x)=|x|\) is shown.

Graph the transformed function \(g(x)=|x|-4\).

Solution:

  • First, we need to identify the transformations and determine how they will affect the graph.
  • The transformed function will make the graph shift down 4 units.
  • So, to create its graph, we can take the 3 points and shift them down 4 units.
  • Now, we can draw 2 rays from the vertex to each point on the left and right to create the V-shape.



Example 2

The graph of the parent function \(f(x)=x^2\) is shown.

Graph the transformed function \(g(x)=(x+2)^2+4\).

Solution:

  • First, we need to identify the transformations and determine how they will affect the graph.
  • The transformed function will make the graph shift left 2 units and up 4 units.
  • So, to create its graph, we can take the 3 points and shift them left 2 units and up 4 units.
  • Now, we can draw the parabola through the 3 green points to make the U-shape.



Example 3

The parent function \(f(x)\) is transformed to create \(g(x)=4f(x-5)\).

How will this affect the graph?

Solution:

  • We know that the 4 multiplied outside the f(x) will stretch it vertically by a factor of 4.
  • The -5 inside the function will shift the function right 5 units.



Example 4

The parent function \(f(x)=|x|\) is transformed to create \(g(x)=|\frac{3}{4}x|+7\).

How will this affect the graph?

Solution:

  • We know that the \(\frac{3}{4}\) multiplied inside will stretch it horizontally by a factor of \(\frac{3}{4}\).
  • The +7 outside the function will shift the function up 7 units.



Conclusion

Understanding transformations allows you to visualize and graph functions efficiently. Today, you learned how vertical and horizontal shifts, stretches, and compressions affect the appearance of a function’s graph. By examining how the function changes when we modify it to forms like\(f(x)+k\), \(f(x+k)\), \(kf(x)\), and \(f(kx)\), you can accurately describe and predict the resulting transformations. Mastery of these concepts lays a strong foundation for graphing more complex functions and analyzing mathematical models in both algebra and real-world contexts.
