🎮 ACTIVITY

Using desmos.com and the functions y=2(1+0.4)^x and y=4(1-0.8)^x, plug the equations into desmos. Click on the settings wheel and make a table of values for each function. Analyze the table of values to identify the y-intercept. Then using successive values, find the ratio that represents the rate of growth or decay. Use these values to write the equation representing the exponential function.

Next, create a real-world situation for the bank about investing an initial amount and a rate of interest. Use the information to create an equation of the exponential function. The compounding time period should be annual to use the exponential function form y=a(1+r)^x.

Make a myrec explaining how to use the table of values to find the initial amount and the rate of growth or decay. Then show how to use this information to generate the equation of the exponential function.

Next, explain how the information in the real-world situation relates to an initial amount, a, and the rate of growth or decay, r. Then show how to use this information to generate the equation of the exponential function.
