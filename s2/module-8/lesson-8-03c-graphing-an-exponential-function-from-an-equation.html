📚 VOCABULARY

Asymptote: A horizontal line that the graph of an exponential function approaches but never crosses. Exponential functions have a horizontal asymptote at \(y=0\) unless there is some constant c added to or subtracted from the end of the function's equation. For example, the function \(f(x)=4(0.25)^x-3\) has an asymptote at the line \(y=-3\).

Base: The base, denoted by 'b' in an exponential function, represents the factor by which the function grows or decays. It is a positive real number greater than 0 and not equal to 1.

Coordinate Plane: A plane formed by two perpendicular number lines, the x-axis (horizontal) and the y-axis (vertical), used for plotting points and graphing functions.

Exponential Decay: The rapid decrease in the value of an exponential function as the input values (x) increase. Exponential decay occurs when the base (b) is between 0 and 1.

Exponential Function: A mathematical function of the form \(f(x)=ab^x\), where 'a' is the initial value, 'b' is the base, and is a positive real number greater than 0 and not equal to 1. Exponential functions exhibit rapid growth or decay as the input value, x, changes.

Exponential Growth: The rapid increase in the value of an exponential function as the input values (x) increase. Exponential growth occurs when the base (b) is greater than 1.

Graph: A visual representation of the relationship between the input values (x) and the output values (y) of a function. Graphs are created by plotting points on a coordinate plane and connecting them.

Growth Factor: The factor by which an exponential function increases at each step. It is calculated by raising the base (b) to the power of the input value (x).

Initial Value: The starting value or y-coordinate of the y-intercept of an exponential function. It is the value of the function when the input (x) is 0.

Smooth Connection: Drawing a continuous, flowing line that accurately represents the behavior of an exponential function between plotted points on a graph.

Y-Intercept: The point where the graph of an exponential function intersects the y-axis. It is represented as (0, a), where 'a' is the initial value. In cases where there is a constant added to or subtracted from the end of the exponential function's equation, the y-intercept is at the point (0, a + c).

💡 EXPLORING THE MATH

In today's lesson, we will explore graphing exponential functions when given an equation representing the exponential function. Understanding how to graph these functions is crucial for visualizing their behavior, which can range from rapid growth to steep decay. Key to this process are the y-intercept and the horizontal asymptote, which serve as guideposts for creating a table of values. This table, in turn, helps us plot the function accurately. We will look at four examples with equations in the forms \(y=a(b)^x\) and \(y=a(1\pm r)^x\), where b is both a whole number and a unit fraction, and r is both positive and negative. Through these examples, you'll learn how to harness these features to graph exponential functions effectively.


Let's review two key features that will help us graph exponential functions. Then watch a short video on how to create the graphs when given a function. Finally, we will dive into a few examples.

Key Features for Graphing

  • Y-intercept: Found by setting \(x=0\) in the equation. This point is where the graph crosses the y-axis.
  • Horizontal Asymptote: A line that the graph approaches but never touches. For exponential functions, this is often \(y=0\), indicating the direction the graph heads as x approaches positive or negative infinity.


Example 1

Consider the function \(y=2(2)^x\). Create a graph to represent the function.

Solution:

Identify the function as growth or decay, the y-intercept, and the horizontal asymptote. Then, create a table of values and a graph to represent the function.

  • Since the value of b is greater than 1, the function represents growth.
  • The initial value is 2. So, the y-intercept is (0, 2).
  • The horizontal asymptote is y=0.

  • We can select 4 x values for the table. Then we substitute the x values into the equation and evaluate for y. Remember that a negative power uses the negative exponent rule; \(a^{-x}=\frac{1}{a^x}\).
  • \(y=2(2)^{-2}=2(\frac{1}{2^2})=2(\frac{1}{4})=\frac{1}{2}\)
  • \(y=2(2)^{-1}=2(\frac{1}{2})=1\)
  • \(y=2(2)^0=2(1)=2\)
  • \(y=2(2)^1=2(2)=4\)
  • Now, we add the y values to the table. Then plot the ordered pairs and the horizontal asymptote.

  • We can then use this graph to sketch the line representing the function.

Conclusion

Graphing exponential functions from equations requires an understanding of the y-intercept and horizontal asymptote, along with the ability to create a helpful table of values. Whether the function represents growth or decay, these features guide us in plotting the graph accurately. By practicing with various forms of exponential functions, you'll develop a strong grasp of how to visualize their impact graphically. This skill is invaluable for interpreting real-world scenarios modeled by exponential functions, from population dynamics to financial forecasting. Always start by identifying the key features, and then build your table of values to ensure a precise and insightful graph.
