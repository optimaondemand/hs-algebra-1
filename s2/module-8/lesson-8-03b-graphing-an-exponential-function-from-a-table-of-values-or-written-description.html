📚 VOCABULARY

Asymptote: A horizontal line that the graph of an exponential function approaches but never crosses. Exponential functions have a horizontal asymptote at \(y=0\) unless there is some constant c added to or subtracted from the end of the function's equation. For example, the function \(f(x)=4(0.25)^x-3\) has an asymptote at the line \(y=-3\).

Base: The base, denoted by 'b' in an exponential function, represents the factor by which the function grows or decays. It is a positive real number greater than 0 and not equal to 1.

Coordinate Plane: A plane formed by two perpendicular number lines, the x-axis (horizontal) and the y-axis (vertical), used for plotting points and graphing functions.

Exponential Decay: The rapid decrease in the value of an exponential function as the input values (x) increase. Exponential decay occurs when the base (b) is between 0 and 1.

Exponential Function: A mathematical function of the form \(f(x)=ab^x\), where 'a' is the initial value, 'b' is the base, and is a positive real number greater than 0 and not equal to 1. Exponential functions exhibit rapid growth or decay as the input value, x, changes.

Exponential Growth: The rapid increase in the value of an exponential function as the input values (x) increase. Exponential growth occurs when the base (b) is greater than 1.

Graph: A visual representation of the relationship between the input values (x) and the output values (y) of a function. Graphs are created by plotting points on a coordinate plane and connecting them.

Growth Factor: The factor by which an exponential function increases at each step. It is calculated by raising the base (b) to the power of the input value (x).

Initial Value: The starting value or y-coordinate of the y-intercept of an exponential function. It is the value of the function when the input (x) is 0.

Smooth Connection: Drawing a continuous, flowing line that accurately represents the behavior of an exponential function between plotted points on a graph.

Y-Intercept: The point where the graph of an exponential function intersects the y-axis. It is represented as (0, a), where 'a' is the initial value. In cases where there is a constant added to or subtracted from the end of the exponential function's equation, the y-intercept is at the point (0, a + c).

 

💡 EXPLORING THE MATH

In today's lesson, we will explore graphing exponential functions using a table of values. This approach is fundamental in understanding how exponential functions behave, whether they are showing growth or decay. A table of values helps us visualize the relationship between the independent variable x and the dependent variable y, laying the groundwork for plotting these points on a graph. By doing so, we can observe the exponential curve's unique characteristics, such as rapid increase or decrease, and identify key features like the y-intercept and the horizontal asymptote. Let's dive into four examples, two of which will involve exponential growth (\(b>1\)) and decay (b is a unit fraction), and two that will demonstrate growth and decay through the rate (r) in functions of the form \(y=a(1\pm r)^x\).


Key Features of Exponential Functions

Before diving into graphing, let's review some essential characteristics of exponential functions. Refer to the image below to see a growth function (green) and two decay functions (red and black) for reference.

  • Rapid Growth or Decay: Exponential functions either grow exponentially (increase rapidly) or decay exponentially (decrease rapidly) as x values change. This results in either a "J"-facing or "L"-facing hockey-stick-like, swooping graph.
  • Base: Exponential functions have a base, denoted by 'b,' which is a positive real number greater than 0 and not equal to 1. Whether b is larger than 1 or strictly between 0 and 1 determines whether the function is a growing or decaying, respectively.
  • Y-Intercept: The graph of an exponential function intersects the y-axis at the point (0, a), where 'a' is the initial value, barring some translation of the graph. In the below image, the initial value is 1 for the green and red graphs.
  • Asymptote: Exponential functions have a horizontal asymptote at \(y=0\), which is represented by the blue dotted line in the image below. If the function is translated up or down by the addition of a positive or negative constant, then the asymptote will shift accordingly.

Graphing Exponential Functions

Example 1

The table of values represents an exponential function. Graph the table of values and the horizontal asymptote to represent the exponential function.

x y
-2 0.5
-1 1
0 2
1 4
2 8

Solution:

Each x and its corresponding y represents an ordered pair for the exponential function.

We identify the ordered pairs, and then graph the points representing the ordered pairs. Then we graph a dashed horizontal line representing the horizontal asymptote \(y=0\).

The ordered pairs are \((-2,0.5), \; (-1,1),\; (0,2),\; (1,4),\; (2,8)\).

We can also identify that the function is exponential growth as the y values are increasing as x increases. The initial value is \(2\), making the y-intercept \((0,2)\).

Creating this graph allows you to create the beginning of the graph to then sketch the curve representing the exponential function.

Conclusion

Creating a graph from a table of values is a vital skill in algebra that allows us to visualize the exponential growth or decay of functions. By carefully plotting the points from our table and connecting them, we form a curve that illustrates the function's behavior over time. Whether we see the curve ascend steeply or descend gradually, these graphs help us grasp the essence of exponential functions—rapid changes that model many phenomena in our world. Practice with different functions and rates to become proficient at recognizing and graphing these compelling mathematical models.
