📚 VOCABULARY

Compounded Annually: The interest that is added to an initial account balance once per year, in the context of calculating compound interest.

Compounded Interest: Interest that is added to the initial amount and subsequent interest earned in each compounding period. It is calculated based on a fixed rate and a specified compounding frequency.

Domain: The set of all possible input values for a function, in the case of exponential functions, the domain is all real numbers unless limited by context.

Exponent: The power to which the base is raised in an exponential function. It determines the effect of increasing or decreasing the function value.

Exponential Function: A function of the form \(f(x)=ab^x\), where \(a\) is the initial value, \(b\) is the base (greater than zero and not equal to 1), and x is the input variable.

Growth Rate: The rate at which an exponential function increases or decreases. If the base (b) is greater than 1, the function exhibits exponential growth. As x increases, the function value increases at an increasing rate. If the base (b) is between 0 and 1, the function exhibits exponential decay. As x increases, the function value decreases at a decreasing rate.

Infinity (∞): A concept representing an unbounded or limitless value. In the context of exponential growth or decay, the graph approaches infinity.

Initial Value: The value of an exponential function when the input variable (x) is zero. It represents the starting point or the value at the beginning.

Input Variable: The independent variable (usually represented by x) in a function that determines the output value.

Output Value: The dependent variable (usually represented by f(x) or y) in a function, which is determined by the input variable.

Range: The set of all possible output values of a function. For exponential functions, the range depends on the base (b). If 0 < b < 1, the range is (∞,0) as the function decays but never reaches zero. If b > 1, the range is (0, ∞) as the function grows without bound.

💡 EXPLORING THE MATH

In today's lesson, we will explore identifying and determining key features of exponential functions when given the graph and equation. Exponential functions, characterized by their constant growth or decay rate, play a vital role in modeling real-world phenomena such as population growth, radioactive decay, and financial investments. Understanding how to identify their growth or decay, growth factor or rate, initial value or y-intercept, horizontal asymptotes, domain, and range is crucial. We'll delve into exponential functions in the forms \(y=ab^x\) and \(y=a(1\pm r)^x\), providing clear examples to illustrate these concepts.


Let's look at the key features. Then we will watch a short video on identifying key features in exponential functions using their graphs and equations.

Key Features Explained

  • Growth or Decay: Determined by the base \(b\) in \(y=ab^x\) or the rate \(r\) in \(y=a(1\pm r)^x\). If \(b>1\) or \(r>0\), the function exhibits growth. If \(0<b<1\) or \(r<0\), it shows decay.
  • Growth or Decay Factor or Rate: \(b\) is the growth or decay factor in \(y=ab^x\), indicating how much the function multiplies or divides per step. In \(y=a(1\pm r)^x\), \(r\) represents the rate of growth or decay as a decimal. We multiply by 100 to find the percent rate of growth or decay.
  • Initial Value or Y-intercept: The value of \(y\) when \(x=0\), represented by \(a\). It's where the graph intersects the y-axis. The y-intercept should be represented as an ordered pair \((0,a)\).
  • Horizontal Asymptotes: A line that the graph approaches but never reaches. For exponential functions, this is typically \(y=0\).
  • Domain and Range: The set of all possible x values (domain) is all real numbers for exponential functions. The range depends on the function's growth or decay; for growth, it's all positive real numbers, and for decay, it depends on the function's orientation.


Let's look at how to describe the end behavior of an exponential function.

End Behavior for Growth

In exponential growth functions, where the base \(b>1\) in \(y=ab^x\) or the rate \(r>0\) in \(y=a(1+r)^x\), the function rises rapidly as x increases.

  • As \(x\) approaches infinity, \(x\rightarrow \infty\), the value of \(y\) also approaches infinity, \(y\rightarrow \infty\). This reflects unlimited growth.
  • As \(x\) approaches negative infinity, \(x\rightarrow -\infty\), the value of \(y\) approaches the horizontal asymptote, usually \(y=0\), if \(a>0\). This means that even as \(x\) decreases without bound, \(y\) levels off and does not become negative.

End Behavior for Decay

In exponential decay functions, where \(0<b<1\) in \(y=ab^x\) or \(r<0\) in \(y=a(1+r)^x\), the function decreases as \(x\) increases, but the decrease slows over time.

  • As \(x\) approaches infinity, \(x\rightarrow \infty\), the value of y approaches the horizontal asymptote, usually \(y=0\), reflecting that the function decreases towards zero but never actually reaches it.
  • As x approaches negative infinity, \(x\rightarrow -\infty\), if \(a>0\), the value of y grows without bound, \(y\rightarrow \infty\). This is because the decay reverses into growth as we look leftward along the x-axis (towards negative x).


Now, let's review some examples.

Example 1

Consider the function \(y=3(2)^x\) with its graph shown. Identify the key features of the exponential function.

Solution:

Key Features:

  • The function represents exponential growth since the value of \(b>1\).
  • The growth factor is \(2\).
  • The initial value is \(3\). So, the y-intercept is \((0,3)\).
  • The horizontal asymptote is \(y=0\).
  • The end behavior of the function is:
    • As \(x\) approaches \(\infty\), then \(y\) approaches \(\infty\).
    • As \(x\) approaches \(-\infty\), then \(y\) approaches \(0\).
  • The Domain and Range are:
    • The domain is all reals written as \(-\infty <x< \infty\).
    • The range starts at the horizontal asymptote and grows. Written as \(y>0\).


Example 2

Consider the function \(y=2(\frac{1}{5})^x\) with its graph shown. Identify the key features of the exponential function.

Solution:

Key Features:

  • The function represents exponential decay since the value of \(b\) is between \(0\) and \(1\).
  • The decay factor is \(\frac{1}{5}\).
  • The initial value is \(2\). So, the y-intercept is \((0,2)\).
  • The horizontal asymptote is \(y=0\).
  • The end behavior of the function is:
    • As \(x\) approaches \(\infty\), then \(y\) approaches \(0\).
    • As \(x\) approaches \(-\infty\), then \(y\) approaches \(\infty\).
  • The Domain and Range are:
    • The domain is all reals written as \(-\infty <x< \infty\).
    • The range starts at infinity and decays to \(0\). Written as \(y>0\).


Example 3

Consider the function \(y=4(1-0.7)^x\) with its graph shown. Identify the key features of the exponential function.

Solution:

Key Features:

  • The function represents exponential decay since the value of \(r\) is negative or \(r<0\).
  • The rate of decay is \(0.7\) or the percent rate of decay is \(70%\).
  • The initial value is \(4\). So, the y-intercept is \((0,4)\).
  • The horizontal asymptote is \(y=0\).
  • The end behavior of the function is:
    • As \(x\) approaches \(\infty\), then \(y\) approaches \(0\).
    • As \(x\) approaches \(-\infty\), then \(y\) approaches \(-\infty\).
  • The Domain and Range are:
    • The domain is all reals written as \(-\infty <x< \infty\).
    • The range starts at infinity and decays to \(0\). Written as \(y>0\).


Example 4

Consider the function \(y=3(1+0.63)^x\) with its graph shown. Identify the key features of the exponential function.

Solution:

Key Features:

  • The function represents exponential growth since the value of r is positive or \(r>0\).
  • The rate of growth is \(0.63\) or a percent rate of growth is \(63%\).
  • The initial value is \(2\). So, the y-intercept is \((0,2)\).
  • The horizontal asymptote is \(y=0\).
  • The end behavior of the function is:
    • As \(x\) approaches \(\infty\), then \(y\) approaches \(\infty\).
    • As \(x\) approaches \(-\infty\), then \(y\) approaches \(0\).
  • The Domain and Range are:
    • The domain is all reals written as \(-\infty <x< \infty\).
    • The range starts at the horizontal asymptote and grows. Written as \(y>0\).


Example 5

Here is another, real-world example. Suppose you have $1,000 in a bank account that earns 5% interest compounded annually. See the graphical representation below, noting that the x-axis and y-axis are using different scales. Based on this description determine the function, then determine the domain, range, asymptote, initial value, and growth factor of the function. Finally, describe its graph's shape.

Solution:

We are told that the bank balance is initially $1,000, so a = 1000. Further, we are told that the account is earning interest at a rate of 5%, or 0.05 in decimal form. But since we know this is a growth function, the base cannot be simply 0.05, for a value between 0 and 1 describes a decay function. The growth must be 5% on top of the initial 100% value, so \(b=1+0.05=1.05\). Now we just need a name for our function ... let us call it "\(B(x)\)" and to substitute the values we found for a and b: \(B(x)=1000(1.05)^x\).

The domain is artificially limited in context to when the bank account is opened, at \(x=0\). So the domain is all real numbers greater than or equal to 0. In interval notation: \(D:\{0\leq x< \infty\}\).

Similarly, the range is limited by the context, namely, to the opening account balance. In interval notation: \(R:\{y>1000\}\).

We have already determined the initial value (1000) and the growth factor (1.05).

There is no relevant asymptote for this function given the context: the range includes all values from the initial value to infinity.

Finally, to the shape of the graph: it starts at (0, 1000) and gradually rises, curving smoothly as x increases.


Conclusion

Identifying and understanding the key features of exponential functions are foundational skills in Algebra 1. Through today's exploration of growth and decay, initial values, growth factors or rates, horizontal asymptotes, and the domain and range of these functions, you're now equipped to analyze both the equations and graphs of exponential functions. Whether you're faced with a problem involving population growth, radioactive decay, or any other scenario modeled by exponential functions, these tools will help you interpret and solve these equations effectively. Remember, practice is key to mastering these concepts, so continue to apply these lessons to various examples.
