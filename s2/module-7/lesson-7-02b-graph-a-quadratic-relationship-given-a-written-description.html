In today's lesson, we will be exploring how to graph a quadratic function that is represented by a written description. We previously learned how to graph using a table of values. We will be using some of the knowledge we gained from that process to help us sketch a graph of a quadratic function when given a written description. A written description will give us particular features of the graph like the vertex and a point it passes through, or the vertex and the y-intercept. As long as we know what the vertex is or can find the vertex, the axis of symmetry will help us generate points on either side of the parabola. A key concept here is using the vertex to find the axis of symmetry, a line that divides the parabola into two mirror-image halves. Let's dive into more graphing of quadratic functions!

Conclusion

Graphing a quadratic function from a description involves understanding and applying the concepts of the vertex, axis of symmetry, and the parabolic shape of the graph. By starting with the vertex and using additional points like given zeros or the y-intercept, you can accurately plot and sketch the quadratic function's graph. This method emphasizes the importance of symmetry in the graph of a quadratic function, allowing for a deeper comprehension of its characteristics and behavior.
