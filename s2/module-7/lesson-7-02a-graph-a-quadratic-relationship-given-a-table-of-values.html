💡 EXPLORING THE MATH

In today's lesson, we will be exploring how to create the graph of a quadratic function that is represented by a table of values. We will use the table of values to plot points and sketch the parabola for the function. We will use the graph we create to determine or estimate any key features shown on the graph. We will explore how the table of values can help us identify any zeros of the function and the vertex of the function. Identifying the vertex will be the most important part, as this is what shows us when the parabola changes directions. Let's dive into graphing quadratic functions from a table of values!

Example 1

The table of values shown represents a quadratic function.

Sketch the parabola of the function using the values and determine key features of the quadratic.

x y
-5 -24
-1 0

  • We will begin by plotting the (x, y) points from the table of values. We do not have to plot every point if they are way out of range. For example, the first ordered pair (-5, -24) is way out of range from the other points. So, we will use the other points to form our graph.
  • We also want to analyze the table of values to identify which one is our vertex.
    • The vertex is the highest or lowest point of the parabola. It is also the point where the function changes directions. We will notice that there are points on either side of the vertex that have equal spacing in the x value with the same y value.
    • The points (-1, 0) and (3, 0) have an x value that is 2 units from -1 and have the same y value of 0. This makes the point (1, 3) our vertex.
  • This means that the Axis of Symmetry is at x=1
    • The axis of symmetry is a line that creates a reflection. Every point has a mirror image over that line.
    • The point (5, -9) will have a mirror image over the AoS that has the same y value and the x value is the same distance from the line.
    • Since 5 is 4 units to the right from 1, then we can go 4 units from 1 to left to find its mirror image. This makes the point (-3, -9) also on the parabola of the function.

Conclusion

Analyzing a table of values will help us visualize the parabola that represents the quadratic function. We can determine the vertex by looking at when the y values change "direction". This means when they go from increasing to decreasing or vice versa. Once we know the vertex, the axis of symmetry can help us find other points using the reflection of given points. This helps us to see the U-shape of the parabola start to form and come into shape. Then we can use the points we have plotted to sketch the parabola. Using the graph we created, we can identify key features. Some key features may need to be estimated if they are not at exact values since we do not have an equation to find them algebraically. In a later lesson, we will explore how to use the table of values to create the equation of the quadratic function. Knowing how to identify key features will help us in that lesson.
