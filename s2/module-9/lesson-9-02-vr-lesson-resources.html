🎮 ACTIVITY YOU'LL COMPLETE

For this activity, spawn an AI character (i.e. Nikola Tesla). Ask the AI character to generate three real-world equations or formulas, each accompanied by a context and a given value for the independent variable (input). These could involve situations such as calculating total cost, determining distance traveled, or modeling population change. For each scenario provided by the AI character, write the scenario description on a sticky note. Then, using the relevant IFXs, create the corresponding equation or formula and place it next to the sticky note to form a complete set: scenario + equation.

Next, use a whiteboard and either the drawpad tool or a 3D pen to evaluate each equation or formula using the provided input value. Calculate the output (dependent variable) by substituting the input into the equation and solving it step-by-step. Make a video recording explaining how you calculated the output for each equation. This video should clearly show the process of plugging in the value, performing operations, and arriving at a solution. Finally, interpret the meaning of the input and output in the context of each real-world scenario—explaining what the input represents, what the output means, and how the equation models the situation overall.
