📚 VOCABULARY

Dependent: The dependent variable is the outcome or result in a function or equation. It's what you're solving for, usually represented as y, and it depends on the value of the independent variable.

Domain: The domain is the set of all possible input values (usually x values) that a function can accept without causing any mathematical problems, like division by zero or taking the square root of a negative number.

Evaluate: To evaluate a function means to find its output value for a given input value. This involves substituting the input value into the function and calculating the result.

Function Notation: Function notation is a way to name and represent functions, using symbols like \(f(x)\) instead of \(y\). The letter \(f\) is the name of the function, and \(x\) represents the input. It provides a clear way to indicate that the value of the function depends on the input value \(x\).

Independent: The independent variable is the input or cause in a function or equation. It's what you choose or vary to see how it affects the dependent variable, usually represented as \(x\).

Input: The input is the value you feed into a function. It's the independent variable that you're testing to see its effect on the output.

Input-Output Relationship: The input-output relationship is the core concept of functions, describing how each input value is connected to an output value. It defines the rule or process the function uses to turn the input into the output.

Output: The output is the result of the function after the input has been processed according to the function's rule. It's the dependent variable that shows how the input was transformed.

Range: The range is the set of all possible output values (usually y values) that a function can produce. It depends on the function's domain and how the function transforms the domain into outputs.

💡 EXPLORING THE MATH

In today's lesson, we will explore evaluating a function for a given input, focusing on function notation, inputs, and outputs, and how these elements are interconnected within the framework of various types of functions. Understanding these concepts is crucial as they form the backbone of not only algebra but also of more advanced mathematical topics you will encounter. Function notation allows us to represent relationships between variables algebraically, where inputs are transformed into outputs through a specific rule. Let's dive into how to evaluate functions using this notation across different types of functions, including linear, quadratic, exponential, and absolute value functions.


Let's begin with reviewing what function notation is and what inputs versus outputs are. Then we will watch a short video on evaluating a function.

Function Notation

  • Function notation is a concise way to define a relationship between two variables. It is written as \(f(x)\), where \(f\) is the name of the function and \(x\) is the input value.
  • This notation helps us easily identify which variable is the input and which expression represents the transformation of that input.

Inputs and Outputs

  • The input is the value we substitute into the function, often represented by \(x\).
  • The output is the result of the function after the input value has been substituted into the expression, often represented by \(f(x)\).

Evaluating a Function for a Given Input

  • To evaluate a function for a given input means to find the output value when a specific input value is substituted into the function.


Example 1

Evaluate the given function for \(f(4)\).

\(f(x)=-5.7x+2\)

Solution:

  • To evaluate the function, we will substitute 4 in for \(x\).
    • \(f(4)=-5.7(4)+2\)
    • It is always best practice to use ( ) when substituting a value in.
    • Then we evaluate the right side using the order of operations to find what \(f(4)\) equals.
    • \(f(4)=-5.7(4)+2 \implies f(4)=-22.8+2 \implies f(4)=-20.8\)

We find that \(f(4)=-20.8\).


Example 2

Evaluate the given function for \(f(-2.1)\).

\(f(x)=2x^2-5x+6.7\)

Solution:

  • To evaluate the function, we will substitute \(-2.1\) for \(x\).
    • \(f(-2.1)=2(-2.1)^2-5(-2.1)+6.7\)
    • It is always best practice to use ( ) when substituting a value in.
    • Then we evaluate the right side using the order of operations to find what \(f(-2.1)\) equals.
    • In this example, we begin with the power of 2. Then proceed to the multiplication. Last addition and subtraction.
    • \(f(-2.1)=2(-2.1)^2-5(-2.1)+6.7 \implies f(-2.1)=2(4.41)-5(-2.1)+6.7 \implies f(-2.1)=8.82+10.5+6.7 \implies f(-2.1)=26.02\)

We find that \(f(-2.1)=26.02\).


Example 3

Evaluate the given function for \(f(3)\).

\(f(x)=32(1-0.62)^x\)

Solution:

  • To evaluate the function, we will substitute \(3\) for \(x\).
    • \(f(3)=32(1-0.62)^3\)
    • It is always best practice to use ( ) when substituting a value in.
    • Then we evaluate the right side using the order of operations to find what \(f(3)\) equals.
    • We can begin by simplifying the subtraction inside the ( ) to \(0.38\). Then we can apply the power. Ending with the multiplication.
    • \(f(3)=32(1-0.62)^3 \implies f(3)=32(0.38)^3 \implies f(3)=32(0.054872) \implies f(3)=1.755904 \implies f(3)\approx 1.76\)
    • This function could give us a decimal that goes on. So, we can round it off. This one is rounded to the nearest hundredths.

We find that \(f(3)\approx 1.76\).


Example 4

Evaluate the given function for \(f(3.62)\).

\(f(x)=3|x-8.14|+5\)

Solution:

  • To evaluate the function, we will substitute \(3.62\) in for \(x\).
    • \(f(3.62)=3|3.62-8.14|+5\)
    • It is always best practice to use ( ) when substituting a value in.
    • Then we evaluate the right side using the order of operations.
    • Work inside the absolute value first like a parenthesis. Once you take the absolute value, it will turn into ( ) representing multiplication. Then multiply and finally add the 5.
    • \(f(3.62)=3|3.62-8.14|+5 \implies f(3.62)=3|-4.52|+5 \implies f(3.62)=3(4.52)+5 \implies f(3.62)=13.56+5 \implies f(3.62)=18.56\)

We find that \(f(3.62)=18.56\).


Conclusion

Evaluating a function for a given input is a fundamental skill in algebra that allows you to understand how inputs are transformed into outputs through the function's specific rule. Whether dealing with linear, quadratic, exponential, or absolute value functions, the process involves substituting the input value into the function and simplifying it to find the output. By mastering this process, you enhance your problem-solving skills and deepen your understanding of how functions model real-world situations and mathematical relationships. Practice with a variety of functions and inputs will solidify your understanding and prepare you for more complex challenges ahead.
