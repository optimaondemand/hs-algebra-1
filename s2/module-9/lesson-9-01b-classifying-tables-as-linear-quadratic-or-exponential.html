📚 VOCABULARY

Absolute Value Function: A function that measures the distance of a number from zero on the number line, regardless of direction. The graph of an absolute value function typically forms a V shape.

Common Difference: The difference between consecutive terms in an arithmetic sequence. It's a constant value that, when added to a term in the sequence, gives the next term.

Common Ratio: The ratio between consecutive terms in a geometric sequence. It's a constant value that, when multiplied by a term in the sequence, gives the next term.

Cube Root Function: A function of the form \(y=ax^3+bx^2+cx+d\), where \(a\neq 0\). Its graph is an S-shaped curve that can extend infinitely in both the positive and negative directions.

Cubic Function: A function that represents the cube root of x, typically written as \(y=\sqrt[3]{x} \)​. Its graph passes through the origin and increases in both the positive and negative directions of x.

Curvature: The rate at which a curve deviates from being a straight line. In algebra, it’s often discussed in the context of quadratic and cubic functions.

Exponential Function: A function where the independent variable appears in the exponent, typically of the form \(y=a(b)^x\), where \(b>0\) and \(b\neq 1\). Its graph shows rapid growth or decay.

Function: A relationship between two sets that assigns exactly one output for each input. It is often represented as \(y=f(x)\).

Growth Rate: The rate at which a quantity increases over time. In the context of exponential functions, it refers to how quickly the function's value increases as x increases.

Linear Function: A function of the form \(y=mx+b\) where \(m\) and \(b\) are constants, and \(m\) is the slope. Its graph is a straight line.

Minimums: The lowest point on the graph of a function. For quadratic functions with a positive leading coefficient, the vertex represents the minimum value.

Maximums: The highest point on the graph of a function. For quadratic functions with a negative leading coefficient, the vertex represents the maximum value.

Quadratic Function: A function of the form \(y=ax^2+bx+c\) where \(a\neq 0\). Its graph is a parabola that can open upwards or downwards.

Sequential: A term used to describe objects (like numbers or functions) that follow a specific order or sequence.

Slope: A measure of the steepness of a line, defined as the ratio of the vertical change to the horizontal change between two points on the line. For linear functions, the slope is the coefficient of \(x\).

Square Root Function: A function that represents the square root of \(x\), written as \(y=\sqrt{x} \)​. Its graph is a half-parabola that opens to the right.

Vertex: The highest or lowest point of a parabola, depending on its direction. The vertex of a quadratic function is a point where the function attains its maximum or minimum value.

💡 EXPLORING THE MATH

In today's lesson, we will explore how to distinguish whether a given table of values represents a linear, quadratic, or exponential function. Being able to identify the type of function from a table of values is a fundamental skill in Algebra 1, allowing students to understand the underlying patterns and behaviors of different mathematical relationships. We'll delve into the noticeable features of tables for each function type and demonstrate mathematically how to determine the function type using common differences for linear and quadratic functions and common ratios for exponential functions. By examining the sequential values in the tables, we can unlock the secrets they hold about the functions they represent.

Recognizing Function Types from Tables

When you're given a table of values, pay attention to how the y-values change as the x-values increase. Here are some tips for identifying the type of function:

  • Linear Functions:

    • The difference between successive y-values (output values) is constant.
    • This constant difference is known as the common difference.

  • Quadratic Functions:

    • The first difference between successive y-values is not constant.
    • The difference between the differences of successive y-values changes at a constant rate.
    • This means that if you take the difference of the differences (second difference), it will be constant.

  • Exponential Functions:

    • The ratio of successive y-values (output values) is constant.
    • This constant ratio is known as the common ratio.


Example 1

The table shown represents a function. Determine if the table represents a linear, quadratic, or exponential function.

x y
-1 -1
0 1
1 3
2 5
3 7

Solution:

  • Observation: The y-values increase by 2 each time the x-value increases by 1.
    • If we subtract the previous y-values from the next y-values, we can find the common difference. 
    • This means to do \(y_2-y_1\) and \(y_3-y_2\) and \(y_4-y_3\). You should always do at least 3 differences to ensure the pattern holds.
    • We will find the first common difference:
      • \(1-(-1)=2\)
      • \(3-1=2\)
      • \(5-3=2\).
  • Determination: This table represents a linear function because it has a constant common difference of 2.


Example 2

The table shown represents a function. Determine if the table represents a linear, quadratic, or exponential function.

x y
0 0
1 2
2 6
3 12
4 20

Solution:

  • Observation: The first differences of y-values are 2, 4, 6, and 8, respectively. The second difference is constant at 2.
    • We begin by taking the common difference same as we did above.
    • Finding the FIRST common difference:
      • \(2-0=2\)
      • \(6-2=4\)
      • \(12-6=6\)
      • \(20-12=8\)
      • These do not create a common difference.
    • But we might notice if we subtract them again, we can get a second common difference.
    • Finding the SECOND common difference:
      • \(4-2=2\)
      • \(6-4=2\)
      • \(8-6=2\)
  • Determination: This table represents a quadratic function because it has a constant second difference of 2.


Example 3

The table shown represents a function. Determine if the table represents a linear, quadratic, or exponential function.

x y
-1 0.5
0 1
1 2
2 4
3 8

Solution:

  • Observation: Each y-value is twice the previous y-value.
    • If we divide the next y-value by the previous, we can see there is a common ratio.
    • This means to do \(\frac{y_2}{y_1}, \frac{y_3}{y_2}, \frac{y_4}{y_3}\)
    • So, we check:
      • \(\frac{1}{0.5}=2\)
      • \(\frac{2}{1}=2\)
      • \(\frac{4}{2}=2\)
      • \(\frac{8}{4}=2\)
  • Determination: This table represents an exponential function because it has a constant common ratio of 2.


Conclusion

In conclusion, by examining the patterns of change in the y-values as the x-values increase, we can determine the type of function a table of values represents. Linear functions have a constant difference between y-values, quadratic functions have a constant second difference between y-values, and exponential functions have a constant ratio between successive y-values. Understanding these key differences and how to identify them is essential for analyzing and interpreting various mathematical relationships and patterns. With practice, distinguishing between linear, quadratic, and exponential functions from a table of values will become a straightforward and invaluable skill in your mathematical toolkit.
