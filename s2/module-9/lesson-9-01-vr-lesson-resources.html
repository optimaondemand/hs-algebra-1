🎮 ACTIVITY YOU'LL COMPLETE

Using the provided list of relevant IFXs create equations and graphs of the functions explored in the lessons. For each, use a sticky note or the 3D pen to identify and label the function type each equation and graph created represents.

Using desmos, graph a linear, quadratic, and exponential function. Using the IFXs, create 3 tables of values for each function. Using the 3D pen show how the function behaves across the x- and y-values. Use sticky notes or a 3D pen to label each one with the type of function it is—linear, quadratic, or exponential. Pay close attention to patterns in the table of values (constant rate of change, changes in rate of change, or growth/decay).

Next, use an AI character (i.e. Nikola Tesla) to search for three real-world scenarios that can be modeled using linear, quadratic, or exponential functions. Examples might include topics like population growth, the trajectory of a ball, or cost over time. Write each of these scenarios on a new sticky note, then determine the function type that best models each situation and use another sticky note or a 3D pen to label each one with the appropriate function type.

Finally, create a video recording explaining how you labeled all components of your project. In your video, clearly state why each equation, table, and graph was identified as that function type, referencing specific patterns in the data or graph or specific terms in the equation. Also, explain how you matched each real-world scenario to the appropriate function type by describing the nature of the change occurring in each scenario. This explanation will demonstrate your understanding of different function types, both in symbolic and visual forms, as well as in applied real-life contexts.
