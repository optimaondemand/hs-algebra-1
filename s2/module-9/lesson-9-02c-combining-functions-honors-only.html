📚 VOCABULARY

Coefficient: A number that multiplies a variable in an algebraic expression.

Constant: A value that does not change; a number without a variable.

Dependent: A variable whose value depends on the value of another variable.

Domain: The set of all possible input values (x-values) for a function.

Evaluate: To find the value of an expression by substituting numbers for variables.

Function: A relation in which each input has exactly one output.

Function Notation: A way to write functions using symbols such as \(f(x)\) to represent the output value of a function for a given input \(x\).

Independent: A variable whose value is freely chosen; it determines the value of the dependent variable.

Input: The value substituted into a function; also known as the independent variable.

Linear Function: A function whose graph is a straight line and has the form \(f(x)=mx+b\).

Output: The value that results from applying a function to an input.

Quadratic Function: A function whose highest exponent is 2, and has the form \(f(x)=ax^2+bx+c\).

Range: The set of all possible output values (y-values) for a function.

Rational Functions: Functions that involve a ratio of polynomials, typically with a variable in the denominator.

Variable: A symbol, usually a letter, used to represent an unknown or changeable value.

💡 EXPLORING THE MATH

In today’s lesson, we will explore how to combine two functions using the four basic arithmetic operations: addition, subtraction, multiplication, and division. These operations allow us to build new functions from existing ones and can be used to model complex relationships in both mathematical and real-world contexts. We will focus on combining linear and quadratic functions. We will also discuss how to evaluate these new functions and identify domain restrictions when necessary, particularly in division.


Combining Functions

When we combine two functions, we create a new function by applying one of the four basic arithmetic operations—addition, subtraction, multiplication, or division—to their outputs.

  • We take the first function and either add it to, subtract it from, multiply it by, or divide it by the second function.
  • We combine like terms and simplify what we are able to using the operation.
  • The new function represents how the two original functions interact, and it can help us model or analyze more complex relationships in both math problems and real-life situations.


Combining Functions Using Arithmetic Operations

Example 1

Let:

\(f(x)=-4x+\frac{3}{2}\)

\(g(x)=5x^2-2.5x+10\)

Find \((f+g)(x)\).

Solution:

  • Let's first understand what \((f+g)(x)\) means.
    • \((f+g)(x) = f(x)+g(x)\)
  • This means that we will use the \(f(x)\) function and \(g(x)\) function to create a new function that combines those two using addition.
  • This will look like \((f+g)(x)=f(x)+g(x)=(-4x+\frac{3}{2})+(5x^2-2.5x+10)\)
  • We will now simplify this expression by combining like terms; i.e., the x terms and the constants. There is only one \(x^2\) term. Therefore, it will stay the same.
    • \((f+g)(x)=(-4x+\frac{3}{2})+(5x^2-2.5x+10)\)
    • \((f+g)(x)=5x^2+(-4x+-2.5x)+(\frac{3}{2}+10)\)
    • \((f+g)(x)=5x^2-6.5x+11.5\)

The resulting function of \((f+g)(x)\) is \(h(x)=5x^2-6.5x+11.5\).



Example 2

Let:

\(f(x)=0.75x^2-x+12\)

\(g(x)=6x-2.33\)

Find \((f-g)(x)\).

Solution:

  • Let's first understand what \((f-g)(x)\) means.
    • \((f-g)(x) = f(x)-g(x)\)
  • This means that we will use the \(f(x)\) function and \(g(x)\) function to create a new function that combines those two using subtraction.
  • This will look like \((f-g)(x)=f(x)-g(x)=(0.75x^2-x+12)-(6x-2.33)\)
  • We will now simplify this expression by combining like terms; i.e., the x terms and the constants. There is only one \(x^2\) term. Therefore, it will stay the same.
    • \((f-g)(x)=(0.75x^2-x+12)-(6x-2.33)\)
    • \((f-g)(x)=0.75x^2+(-x-6x)+(12-(-2.33))\) - note that we used the subtraction in the ( ) when combining like terms. So, we are SUBTRACTING the 6x from the 12x and we are SUBTRACTING the -2.33 from the 12.
    • \((f-g)(x)=0.75x^2-7x+14.33\)

The resulting function of \((f-g)(x)\) is \(h(x)=0.75x^2-7x+14.33\).



Example 3

Let:

\(f(x)=0.5x-8\)

\(g(x)=-x^2+3x-5\)

Find \((f\cdot g)(x)\).

Solution:

  • Let's first understand what \((f\cdot g)(x)\) means.
    • \((f\cdot g)(x) = f(x)\cdot g(x)\)
  • This means that we will use the \(f(x)\) function and \(g(x)\) function to create a new function that combines those two using multiplication.
  • This will look like \((f\cdot g)(x)=f(x)\cdot g(x)=(0.5x-8)(-x^2+3x-5)\)
  • We will begin by using distribution to multiply the first expression by the second expression. Then, we can simplify this expression by combining like terms.
    • \((f\cdot g)(x)=(0.5x-8)(-x^2+3x-5)\)
    • \((f-g)(x)=(0.5x(-x^2)+0.5x(3x)+0.5x(-5))+(-8(-x^2)+-8(3x)+-8(-5))\) - note we multiply the 0.5x by each term in the second ( ). Then we multiply the -8 by each term.
    • \((f-g)(x)=-0.5x^3+1.5x^2-2.5x+8x^2-24x+40\)
    • \((f-g)(x)=-0.5x^3+9.5x^2-26.5x+40\)

The resulting function of \((f\cdot g)(x)\) is \(h(x)=-0.5x^3+9.5x^2-26.5x+40\).



Example 4

Let:

\(f(x)=2x^2+x-4\)

\(g(x)=-3x+6\)

Find \((f\div g)(x)\).

Solution:

  • Let's first understand what \((f\div g)(x)\) means.
    • \((f\div g)(x) = f(x)\div g(x)=\Large \frac{f(x)}{g(x)}\)
  • This means that we will use the \(f(x)\) function and \(g(x)\) function to create a new function that combines those two using division.
  • This will look like \((f\div g)(x)=f(x)\div g(x)=\Large \frac{2x^2+x-4}{-3x+6}\)
  • We can see if the quadratic will factor to see if any binomials would cancel. Once we get the new function, we will need to check the denominator for domain restrictions since dividing by 0 results in a domain error. 
    • \((f\div g)(x)=\Large \frac{2x^2+x-4}{-3x+6}\)
    • \(2x^2+x-4\) is not factorable. Therefore, there is nothing to simplify.
  • Since \(-3x+6\) is in the denominator, we need to look for restrictions on the denominator.
  • Restrictions happen when \(-3x+6=0\).
  • If we solve that for \(x\), we find that if \(x=2\) we will get a 0 in the denominator.
  • So, the domain of the new function is \(D=\{\mathbb{R} | x\neq 2\}\).

The resulting function of \((f\div g)(x)\) is \(h(x)=\Large \frac{2x^2+x-4}{-3x+6}\) and its domain is \(D=\{\mathbb{R} | x\neq 2\}\).



Example 5

Let:

\(f(x)=5x-7.5\)

\(g(x)=x^2-5x+6\)

Find \((f\div g)(x)\).

Solution:

  • Let's first understand what \((f\div g)(x)\) means.
    • \((f\div g)(x) = f(x)\div g(x)=\Large \frac{f(x)}{g(x)}\)
  • This means that we will use the \(f(x)\) function and \(g(x)\) function to create a new function that combines those two using division.
  • This will look like \((f\div g)(x)=\Large \frac{f(x)}{g(x)}=\Large \frac{5x-7.5}{x^2-5x+6}\)
  • We can see if the quadratic will factor to see if any binomials would cancel. Once we get the new function, we will need to check the denominator for domain restrictions since dividing by 0 results in a domain error and is undefined. 
    • \((f\div g)(x)=\Large \frac{5x-7.5}{x^2-5x+6}\)
    • \(x^2-5x+6\) is factorable.
    • \(x^2-5x+6=(x-2)(x-3)\) - Neither of the binomials is similar to the numerator. So, nothing will simplify.
  • Since \(x^2-5x+6\) is in the denominator, we need to look for restrictions on the denominator.
  • Restrictions happen when \(x^2-5x+6=0\). We need to factor and solve the quadratic. This will give us 2 x-values.
    • \(x^2-5x+6=0 \implies (x-2)(x-3)=0 \implies x-2=0\; or\; x-3=0\)
  • If we solve that for \(x\), we find that if \(x=2\) or \(x=3\) we will get a 0 in the denominator.
  • So, the domain of the new function is \(D=\{\mathbb{R} | x\neq 2\; and\; x\neq 3\}\).

The resulting function of \((f\div g)(x)\) is \(h(x)=\Large \frac{5x-7.5}{x^2-5x+6}\) and its domain is \(D=\{\mathbb{R} | x\neq 2\; and\; x\neq 3\}\).



Real-World Examples for Combining Functions

Example 1

Let:

  • \(f(x)=15x+50\), where \(x\) is the number of hours worked and $50 is a fixed bonus.
  • \(g(x)=-0.5x^2+20x\), where \(x\) is the hours of productivity and the pay decreases after peak productivity.

Find \((f+g)(x)\) that models the total income from the two different jobs.

Solution:

  • We know that \((f+g)(x)=f(x)+g(x)=(15x+50)+(-0.5x^2+20x)\).
  • By simplifying this:
    • \((f+g)(x)=(15x+50)+(-0.5x^2+20x)\)
    • \((f+g)(x)=-0.5x^2+(15x+20x)+50\)
    • \((f+g)(x)=-0.5x^2+35x+50\)
  • We find that the function \(h(x)=-0.5x^2+35x+50\) models the total income for both jobs.



Example 2

Let:

  • \(f(x)=30-0.2x\) be the miles per gallon of a car after driving \(x\) miles.
  • \(g(x)=2x+10\) be the total gallons of gas consumed after driving \(x\) miles.

Find \((f\div g)(x)\) that models the miles per gallon per gallon consumed of the car.

Solution:

  • We know that \((f\div g)(x)=f(x)\div g(x)=\Large \frac{30-0.2x}{2x+10}\).
  • The domain restriction happens when \(2x+10=0\). So we find that if \(x=-5\), the function is undefined.
  • We find that the function \(h(x)=\Large \frac{30-0.2x}{2x+10}\) models the miles per gallon per gallon consumed.


Conclusion

By combining linear and quadratic functions through addition, subtraction, multiplication, and division, we can create new functions that represent more complex relationships. This helps us analyze real-world problems with greater flexibility. We also learned how to evaluate these new functions, determine their types based on operations, and find domain restrictions, especially when dividing. Mastering these skills strengthens our understanding of functions and prepares us to build and analyze models in more advanced math and real-life scenarios.
